## S1-L1 · 충전 기록

하루별 배터리 잔량의 변화량 N개가 입력 순서대로 주어진다. 양수는 충전, 음수는 소모, 0은 변화가 없음을 뜻한다. 양수 값만 모두 더하라. 양수가 없다면 0을 출력한다.

### 입력
첫 줄에 테스트케이스 수 T(1≤T≤3)가 주어진다. 각 테스트케이스마다 첫 줄 N(1≤N≤100), 다음 줄 정수 N개(-100≤값≤100).

### 출력
각 테스트케이스의 정답을 '#tc 정답' 형식으로 한 줄씩 출력한다. 양수 변화량의 합.

### 예제
```text
2
5
3 -2 0 7 -4
1
-8
```
```text
#1 10
#2 0
```

### 문제 유형
구현 / 순회

### 핵심 구조
각 값을 순서대로 읽고 0보다 큰 값만 누적하세요.

### 정답 코드
```python
def solve_case():
    n=int(input()); a=list(map(int,input().split())); print(sum(x for x in a if x>0))
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

## S1-L2 · 보관함 잠금 로그

문자열은 (, ), [, ] 네 기호만으로 이루어진다. 각 닫는 괄호가 가장 최근의 같은 종류 여는 괄호와 짝을 이루고, 모든 괄호가 짝지어지면 YES를 출력한다. 그 외에는 NO를 출력한다.

### 입력
첫 줄에 테스트케이스 수 T(1≤T≤3)가 주어진다. 각 테스트케이스마다 괄호로만 이루어진 문자열 한 줄(1≤길이≤30). 공백은 없다.

### 출력
각 테스트케이스의 정답을 '#tc 정답' 형식으로 한 줄씩 출력한다. YES 또는 NO.

### 예제
```text
2
([])
([)]
```
```text
#1 YES
#2 NO
```

### 문제 유형
스택

### 핵심 구조
여는 기호를 쌓고 닫는 기호에서는 맨 위를 비교하세요. 마지막에 스택이 비어야 합니다.

### 정답 코드
```python
def solve_case():
    s=input().strip(); st=[]; pair={')':'(',']':'['}; ok=True
    for c in s:
     if c in '([': st.append(c)
     elif not st or st.pop()!=pair[c]: ok=False; break
    print('YES' if ok and not st else 'NO')
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

## S1-L3 · 폐쇄된 통로

S에서 E까지 상하좌우로 한 칸씩 이동한다. .은 이동할 수 있는 칸이고 #은 들어갈 수 없는 벽이다. S와 E도 지나갈 수 있다. 최소 이동 횟수를 구하고, 도착할 수 없다면 -1을 출력한다.

### 입력
첫 줄에 테스트케이스 수 T(1≤T≤3)가 주어진다. 각 테스트케이스마다 첫 줄 R C(1≤R,C≤6, R×C≥2). 이어서 길이가 C인 지도 R줄. S와 E는 서로 다른 칸에 하나씩 있다.

### 출력
각 테스트케이스의 정답을 '#tc 정답' 형식으로 한 줄씩 출력한다. S에서 E까지의 최소 이동 횟수 또는 -1.

### 예제
```text
2
3 4
S...
##.#
...E
1 2
SE
```
```text
#1 5
#2 1
```

### 문제 유형
그래프 탐색 / BFS

### 핵심 구조
S에서 시작해 큐로 거리 순서대로 탐색하고, 방문한 칸은 다시 넣지 마세요.

### 정답 코드
```python
def solve_case():
    from collections import deque
    r,c=map(int,input().split()); g=[input().strip() for _ in range(r)]; sr,sc=next((i,j) for i in range(r) for j in range(c) if g[i][j]=='S'); q=deque([(sr,sc,0)]); seen={(sr,sc)}; ans=-1
    while q:
     i,j,d=q.popleft()
     if g[i][j]=='E': ans=d; break
     for di,dj in ((1,0),(-1,0),(0,1),(0,-1)):
      ni,nj=i+di,j+dj
      if 0<=ni<r and 0<=nj<c and g[ni][nj]!='#' and (ni,nj) not in seen: seen.add((ni,nj)); q.append((ni,nj,d+1))
    print(ans)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

## S1-L5 · 정찰대 편성

서로 구별되는 대원 N명의 능력치가 주어진다. 정확히 K명을 골라 능력치 합이 V가 되는 선택의 수를 구하라.
능력치가 같아도 대원 번호가 다르면 다른 선택이다. 선택 순서는 고려하지 않는다. K=0일 때 빈 선택 하나의 합은 0이다.

### 입력
첫 줄에 테스트케이스 수 T(1≤T≤3)가 주어진다. 각 테스트케이스마다 N K V(1≤N≤12, 0≤K≤N, 0≤V≤108). 다음 줄 능력치 N개(0~9).

### 출력
각 테스트케이스의 정답을 '#tc 정답' 형식으로 한 줄씩 출력한다. 조건을 만족하는 선택 수.

### 예제
```text
2
6 0 2
9 2 4 7 0 9
11 3 16
4 9 3 2 8 9 8 1 2 9 5
```
```text
#1 0
#2 11
```

### 문제 유형
부분집합 / 비트마스크

### 핵심 구조
비트마스크마다 선택한 원소 수와 합을 함께 세세요.

### 정답 코드
```python
def solve_case():
    n,k,target=map(int,input().split())
    a=list(map(int,input().split()))
    answer=0
    for mask in range(1<<n):
        count=0
        total=0
        for i in range(n):
            if mask & (1<<i):
                count+=1
                total+=a[i]
        if count==k and total==target:
            answer+=1
    print(answer)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

## S2-L3 · 분리된 기지

번호가 1부터 N까지인 기지를 양방향 통로가 연결한다. 서로 통로를 따라 오갈 수 있는 기지들을 한 묶음으로 볼 때, 전체 묶음 수를 구하라. 통로가 없는 기지는 각각 하나의 묶음이다.

### 입력
첫 줄에 테스트케이스 수 T(1≤T≤3)가 주어진다. 각 테스트케이스마다 첫 줄 N M(1≤N≤15, 0≤M≤25). 다음 M줄에 서로 다른 기지 u v(1≤u,v≤N). 같은 통로가 중복으로 주어질 수 있다.

### 출력
각 테스트케이스의 정답을 '#tc 정답' 형식으로 한 줄씩 출력한다. 연결된 기지 묶음의 수.

### 예제
```text
2
5 2
1 2
4 5
1 0
```
```text
#1 3
#2 1
```

### 문제 유형
그래프 탐색

### 핵심 구조
아직 방문하지 않은 기지에서 탐색을 시작할 때마다 묶음 수를 하나 올리세요.

### 정답 코드
```python
def solve_case():
    n,m=map(int,input().split()); g=[[] for _ in range(n+1)]
    for _ in range(m):
     u,v=map(int,input().split()); g[u].append(v); g[v].append(u)
    seen=set(); ans=0
    for i in range(1,n+1):
     if i in seen: continue
     ans+=1; seen.add(i); stack=[i]
     while stack:
      for v in g[stack.pop()]:
       if v not in seen: seen.add(v); stack.append(v)
    print(ans)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

## S2-L4 · 교환권 최소 사용

서로 다른 가치의 교환권 N종류가 있고, 각 종류를 원하는 만큼 사용할 수 있다. 가치의 합을 정확히 V로 만드는 데 필요한 최소 장수를 구하라. 만들 수 없다면 -1, V가 0이라면 0을 출력한다.

### 입력
첫 줄에 테스트케이스 수 T(1≤T≤3)가 주어진다. 각 테스트케이스마다 첫 줄 N V(1≤N≤6, 0≤V≤50). 다음 줄 서로 다른 교환권 가치 N개(1≤가치≤50).

### 출력
각 테스트케이스의 정답을 '#tc 정답' 형식으로 한 줄씩 출력한다. 필요한 최소 장수 또는 -1.

### 예제
```text
2
3 11
1 5 7
2 3
2 4
```
```text
#1 3
#2 -1
```

### 문제 유형
동적 계획법

### 핵심 구조
dp[x]를 x를 만드는 최소 장수로 정의하고, 작은 금액부터 각 교환권을 시험하세요.

### 정답 코드
```python
def solve_case():
    n,v=map(int,input().split()); coins=list(map(int,input().split())); dp=[10**9]*(v+1); dp[0]=0
    for x in range(1,v+1):
     for c in coins:
      if c<=x: dp[x]=min(dp[x],dp[x-c]+1)
    print(dp[v] if dp[v]<10**9 else -1)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

## S2-L5 · 완전 트리의 관측 구역

## S3-L2 · 돌아가는 인쇄 대기열

0부터 N-1까지 순서대로 놓인 문서에 중요도가 있다. 맨 앞 문서보다 중요도가 높은 문서가 큐에 하나라도 남아 있으면 그 문서를 맨 뒤로 보낸다. 그렇지 않으면 인쇄한다. 중요도가 같은 문서는 현재 순서를 따른다. 처음 위치 K인 문서가 몇 번째로 인쇄되는지 구하라.

첫 줄에 테스트케이스 수 T(1≤T≤3)가 주어진다. 각 테스트케이스마다 첫 줄 N K(1≤N≤10, 0≤K<N). 다음 줄 중요도 N개(1≤중요도≤9).

### 출력
각 테스트케이스의 정답을 '#tc 정답' 형식으로 한 줄씩 출력한다. K번 문서의 인쇄 순서(첫 번째는 1).


```text
#2 1
```

### 문제 유형

### 핵심 구조
(원래 인덱스, 중요도)를 큐에 넣고 맨 앞이 현재 최대 중요도보다 작으면 뒤로 이동시키세요.

```python
    from collections import deque
    n,k=map(int,input().split()); a=list(map(int,input().split())); q=deque(enumerate(a)); cnt=0
    while q:
     i,p=q.popleft()
     if any(other>p for _,other in q): q.append((i,p))
     else:
      cnt+=1
      if i==k: print(cnt); break
```

### 핵심 구조

```python
    n=int(input())
    g=[list(input().strip()) for _ in range(n)]
    answer=0
    for r in range(n):
        for c in range(n):
            if g[r][c]!='1': continue
            answer+=1
            g[r][c]='0'
            st=[(r,c)]
            while st:
                x,y=st.pop()
                for dx,dy in ((1,0),(-1,0),(0,1),(0,-1)):
                    nx,ny=x+dx,y+dy
                    if 0<=nx<n and 0<=ny<n and g[nx][ny]=='1':
                        g[nx][ny]='0'
                        st.append((nx,ny))
    print(answer)
```

## S5-L4 · 이진 탐색 횟수

페이지는 1부터 P까지다. left=1, right=P로 시작하고 center=(left+right)//2를 계산한다. 목표면 종료하고, 목표가 작으면 right=center-1, 크면 left=center+1로 바꾼다.
목표 A와 B를 각각 찾을 때 계산한 center 횟수를 비교한다. A가 적으면 A, B가 적으면 B, 같으면 TIE를 출력한다.

### 입력
첫 줄에 테스트케이스 수 T(1≤T≤3)가 주어진다. 각 테스트케이스마다 P A B(1≤A,B≤P≤1000000).

### 출력
각 테스트케이스의 정답을 '#tc 정답' 형식으로 한 줄씩 출력한다. A, B 또는 TIE.

### 예제
```text

2 1 2
```
```text

#2 A
```

### 문제 유형
이진 탐색

### 핵심 구조
두 목표에 같은 탐색 함수를 적용하고 center를 계산할 때마다 횟수를 늘리세요.

### 정답 코드
```python
def solve_case():
    p,a,b=map(int,input().split())
    def search(target):
        l,r=1,p
        count=0
        while l<=r:
            count+=1
            m=(l+r)//2
            if m==target: return count
            if target<m: r=m-1
            else: l=m+1
    x,y=search(a),search(b)
    print('A' if x<y else 'B' if y<x else 'TIE')
T = int(input())
```

## FA-L2 · 청색 전송 미로

N×N 격자에서 왼쪽 위에서 오른쪽 아래로 이동한다. 상하좌우으로 한 칸씩 움직이며 1인 칸에는 들어갈 수 없다.

### 입력

각 테스트케이스의 정답을 '#tc 정답' 형식으로 한 줄씩 출력한다. 최소 이동 횟수 또는 -1.

### 핵심 구조
방문 칸을 기록하며 큐에서 가까운 칸부터 꺼내세요.

### 정답 코드
```python
def solve_case():
    n=int(input())
    g=[input().strip() for _ in range(n)]
    q=[(0,0,0)]
    seen={(0,0)}
    head=0
    answer=-1
    while head<len(q):
        r,c,d=q[head]
        head+=1
        if r==n-1 and c==n-1:
            answer=d
            break
        for dr,dc in ((1,0),(-1,0),(0,1),(0,-1)):
            nr,nc=r+dr,c+dc
            if 0<=nr<n and 0<=nc<n and g[nr][nc]=='0' and (nr,nc) not in seen:
                seen.add((nr,nc))
                q.append((nr,nc,d+1))
    print(answer)
T = int(input())
```

처음 K개 합을 구하고 한 칸 이동할 때 빠진 값을 빼고 새 값을 더하세요.

### 정답 코드
```python
def solve_case():
    n,k=map(int,input().split())
    a=list(map(int,input().split()))
    s=sum(a[:k])
    ans=s
    for i in range(k,n):
        s+=a[i]-a[i-k]
        ans=max(ans,s)
    print(ans)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

## FB-L2 · 적색 전송 미로

N×N 격자에서 왼쪽 위에서 오른쪽 아래로 이동한다. 네 대각선 방향으로 한 칸씩 움직이며 1인 칸에는 들어갈 수 없다.
한 번 이동할 때 1회로 센다. 도착할 수 없으면 -1을 출력한다. 대각선 사이의 가로·세로 칸은 검사하지 않는다.

### 입력
첫 줄에 테스트케이스 수 T(1≤T≤3)가 주어진다. 각 테스트케이스마다 N(2≤N≤10). 다음 N줄에 공백 없는 0,1 문자열. 시작과 도착 칸은 0이다.

### 출력
각 테스트케이스의 정답을 '#tc 정답' 형식으로 한 줄씩 출력한다. 최소 이동 횟수 또는 -1.

### 예제
```text
2
2
00
10
3
000
000
010
```
```text
#1 1
#2 2
```

### 문제 유형
BFS / 최단 거리

### 핵심 구조
방문 칸을 기록하며 큐에서 가까운 칸부터 꺼내세요.

### 정답 코드
```python
def solve_case():
    n=int(input())
    g=[input().strip() for _ in range(n)]
    q=[(0,0,0)]
    seen={(0,0)}
    head=0
    answer=-1
    while head<len(q):
        r,c,d=q[head]
        head+=1
        if r==n-1 and c==n-1:
            answer=d
            break
        for dr,dc in ((1,1),(1,-1),(-1,1),(-1,-1)):
            nr,nc=r+dr,c+dc
            if 0<=nr<n and 0<=nc<n and g[nr][nc]=='0' and (nr,nc) not in seen:
                seen.add((nr,nc))
                q.append((nr,nc,d+1))
    print(answer)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

## FB-L3 · 적색 트리 암호

노드 번호 1~N의 완전 이진 트리에 중위 순회(왼쪽, 자신, 오른쪽) 순서로 N부터 1까지 감소하는 값을 저장한다.
루트에 저장된 값과 노드 K에 저장된 값을 출력하라. 자식 번호가 N을 넘으면 그 자식은 없다.

### 입력
첫 줄에 테스트케이스 수 T(1≤T≤3)가 주어진다. 각 테스트케이스마다 N K(1≤K≤N≤500).

### 출력
각 테스트케이스의 정답을 '#tc 정답' 형식으로 한 줄씩 출력한다. 루트 값과 K번 노드 값, 공백 구분.

### 예제
```text
2
1 1
2 2
```
```text
#1 1 1
#2 1 2
```

### 문제 유형
이진 트리 / 중위 순회

### 핵심 구조
노드 번호와 노드에 저장하는 값을 구분하고 순회 중 현재 값을 배정하세요.

### 정답 코드
```python
def solve_case():
    n,k=map(int,input().split())
    a=[0]*(n+1)
    value=[n]
    def visit(i):
        if i>n: return
        visit(i*2)
        a[i]=value[0]
        value[0]+=-1
        visit(i*2+1)
    visit(1)
    print(a[1],a[k])
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

## FB-L4 · 적색 경로 해독

방향이 있는 도로의 통행료가 주어진다. 1~N-1번 각각에서 N번으로 가는 최소 통행료를 번호 순서대로 구하라. 모든 해당 경로는 존재한다.

### 핵심 구조
A형은 출발점에서 탐색하세요. B형은 모든 도로를 뒤집고 도착점에서 탐색하면 각 출발점의 비용을 한 번에 구할 수 있습니다.

### 정답 코드
```python
def solve_case():
    import heapq
    n,m=map(int,input().split())
    g=[[] for _ in range(n+1)]
    for _ in range(m):
        u,v,w=map(int,input().split())
        g[v].append((u,w))
    start=n
    dist=[10**9]*(n+1)
    dist[start]=0
    q=[(0,start)]
    while q:
        cost,u=heapq.heappop(q)
        if cost!=dist[u]: continue
        for v,w in g[u]:
            if cost+w<dist[v]:
                dist[v]=cost+w
                heapq.heappush(q,(dist[v],v))
    print(*dist[1:n])
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

## FB-L5 · 적색 최종 장치

일렬로 놓인 N개 장치에서 정확히 K개를 선택한다. 바로 이웃한 두 장치를 동시에 선택할 수 없다. 첫 장치와 마지막 장치는 이웃이 아니다.
선택한 장치 비용 합의 최대값을 구하라.
일반 입력 형식과 예제로 코드를 미리 작성할 수 있다. 승리 판정에는 레벨 4 정답 후 공개되는 팀 전용 비용 목록을 사용하는 최종 검증이 추가된다. 그 전에는 레벨 5 제출이 잠겨 있다.

### 입력
첫 줄에 테스트케이스 수 T(1≤T≤3)가 주어진다. 각 테스트케이스마다 N K(4≤N≤15, 1≤K≤(N+1)//2). 다음 줄 양의 비용 N개(1~450).

### 출력
각 테스트케이스의 정답을 '#tc 정답' 형식으로 한 줄씩 출력한다. 조건에 맞는 최대 비용 합.

### 예제
```text
2
11 4
198 10 303 92 355 74 318 195 337 415 134
15 1
214 352 379 151 254 450 156 212 69 175 47 203 383 311 136
```
```text
#1 1391
#2 450
```

### 문제 유형
백트래킹 / 조합

### 핵심 구조
현재 장치를 고르면 다음 장치는 건너뛰세요. 고른 개수가 K일 때 비용 합을 후보에 넣으세요.

### 정답 코드
```python
def solve_case():
    n,k=map(int,input().split())
    a=list(map(int,input().split()))
    answers=[]
    def dfs(i,count,total):
        if count==k:
            answers.append(total)
            return
        if i>=n: return
        dfs(i+1,count,total)
        dfs(i+2,count+1,total+a[i])
    dfs(0,0,0)
    print(max(answers))
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```
