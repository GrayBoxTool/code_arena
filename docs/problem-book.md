# S1-L1 · 충전 기록

## 문제 설명

배터리의 충전·사용 기록 N개가 시간순으로 주어집니다. 양수는 충전된 양, 음수는 사용한 양, 0은 변화가 없음을 뜻합니다.  
  
이 문제에서는 잔량이나 순변화량이 아니라, 기록에 나타난 총 충전량을 구합니다. 따라서 양수인 기록만 더하고 음수와 0은 합에 포함하지 마세요.  
  
양수인 기록이 하나도 없다면 총 충전량은 0입니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 기록 수 N이 주어집니다.  
다음 줄에 N개의 변화량이 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 100
- -100 ≤ 각 변화량 ≤ 100

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
양수 변화량만 더한 총 충전량을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
5
3 -2 0 7 -4
3
-8 0 -1
```

## 예제 출력

```text
#1 10
#2 0
```

## 예제 해설

첫 번째는 3과 7만 충전 기록이므로 3 + 7 = 10입니다.  
두 번째에는 양수가 없으므로 0입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.

```python
def solve_case():
    s = input().strip()
    st = []
    pair = {')': '(', ']': '['}
    ok = True
    for c in s:
        if c in '([':
            st.append(c)
        elif not st or st.pop() != pair[c]:
            ok = False
            break
    print('YES' if ok and (not st) else 'NO')
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

# S1-L3 · 폐쇄된 통로

## 문제 설명

통로 지도가 R행 C열로 주어집니다. S는 출발 칸, E는 도착 칸, .은 빈 칸, #은 벽입니다.  
  
현재 칸에서 상하좌우로 인접한 칸으로 한 번에 한 칸 이동할 수 있습니다. 벽으로 들어가거나 지도 밖으로 나갈 수 없으며, 대각선 이동도 허용하지 않습니다.  
  
S에서 E까지 가는 최소 이동 횟수를 구하세요. 출발 칸에 서 있는 상태는 0회이며, 바로 옆의 E로 이동하면 1회입니다. 도착할 방법이 없으면 -1을 출력합니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 행 수 R과 열 수 C가 주어집니다.  
다음 R줄에는 길이 C인 지도 문자열이 주어집니다. 행 안에는 공백이 없습니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
R C
row1
row2
...
rowR
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ R, C ≤ 6, R × C ≥ 2
- S와 E는 서로 다른 칸에 각각 한 번 등장합니다.
- 그 외의 문자는 . 또는 #입니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
최소 이동 횟수를 출력합니다. 도달할 수 없다면 -1입니다.

```text
#tc answer
```

## 예제 입력

```text

3 4
S...
##.#
...E

S#

```

## 예제 출력

```text

```

## 예제 해설

첫 번째는 오른쪽, 오른쪽, 아래, 아래, 오른쪽 순서로 이동하면 5회입니다. 더 짧게는 도착할 수 없습니다.  
두 번째는 출발 칸에서 이동할 수 없어 -1입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.

## 문제 유형 공개

## 핵심 구조 공개

S에서 시작해 큐로 거리 순서대로 탐색하고, 방문한 칸은 다시 넣지 마세요.


---

# S1-L3 · 모범 풀이

```python
def solve_case():
    from collections import deque
    r, c = map(int, input().split())
    g = [input().strip() for _ in range(r)]
    sr, sc = next(((i, j) for i in range(r) for j in range(c) if g[i][j] == 'S'))
    q = deque([(sr, sc, 0)])
    seen = {(sr, sc)}
    ans = -1
    while q:
        i, j, d = q.popleft()
        if g[i][j] == 'E':
            ans = d
            break
        for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            ni, nj = (i + di, j + dj)
            if 0 <= ni < r and 0 <= nj < c and (g[ni][nj] != '#') and ((ni, nj) not in seen):
                seen.add((ni, nj))
                q.append((ni, nj, d + 1))
    print(ans)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

# S1-L4 · 작업 시간표

```python
def solve_case():
    n = int(input())
    jobs = sorted((tuple(map(int, input().split())) for _ in range(n)), key=lambda x: x[1])
    end = -1
    count = 0
    for s, e in jobs:
        if s >= end:
            end = e
            count += 1
    print(count)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

# S1-L5 · 정찰대 편성

정찰대 후보 N명에게 각각 능력치가 있습니다. 후보들은 1번부터 N번까지 번호로 구별됩니다.

첫 줄에 후보 수 N, 선택할 인원 K, 목표 합 V가 주어집니다.  
다음 줄에 후보들의 능력치 N개가 번호순으로 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text

a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 12

```python
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        g[u].append(v)

    seen = set()

        ans += 1
```

노드 번호가 1부터 N까지인 완전 이진 트리가 있습니다. 노드 i의 왼쪽 자식은 2 × i, 오른쪽 자식은 2 × i + 1이며, 번호가 N을 넘는 자식은 존재하지 않습니다.  
  
관측 장비를 K번 노드에 설치합니다. 관측 범위에는 K번 노드 자신과, 자식 방향으로 내려가며 만나는 모든 자손 노드가 포함됩니다.  
  
관측 범위에 포함되는 노드의 수를 구하세요. K번 노드의 부모나 형제는 포함하지 않습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
각 테스트케이스마다 한 줄에 전체 노드 수 N과 장비를 설치할 노드 번호 K가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N K
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ K ≤ N ≤ 1000

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
K번 노드 자신을 포함한 서브트리의 노드 수를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
10 2
7 4
```

## 예제 출력

```text
#1 6
#2 1
```

## 예제 해설

첫 번째는 노드 2, 4, 5, 8, 9, 10이 포함되어 6개입니다.  
두 번째의 4번 노드는 자식이 없으므로 자신 하나만 포함되어 1입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.

# S2-L5 · 모범 풀이

```python
def solve_case():
    n, k = map(int, input().split())

    def count(x):
        if x > n:
            return 0
        return 1 + count(x * 2) + count(x * 2 + 1)
    print(count(k))
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

# S3-L2 · 모범 풀이

```python
def solve_case():
    from collections import deque
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    q = deque(enumerate(a))
    cnt = 0
    while q:
        i, p = q.popleft()
        if any((other > p for _, other in q)):
            q.append((i, p))
        else:
            cnt += 1
            if i == k:
                print(cnt)
                break
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

# S3-L3 · 모범 풀이

```python
def solve_case():
    n, t = map(int, input().split())
    a = sorted(map(int, input().split()))
    l = 0
    r = n - 1
    ans = 0
    while l < r:
        s = a[l] + a[r]
        if s == t:
            ans += 1
            l += 1
            r -= 1
        elif s < t:
            l += 1
        else:
            r -= 1
    print(ans)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

```python
def solve_case():
    n = int(input())
    g = [list(input().strip()) for _ in range(n)]
    answer = 0
    for r in range(n):
        for c in range(n):
            if g[r][c] != '1':
                continue
            answer += 1
            g[r][c] = '0'
            st = [(r, c)]
            while st:
                x, y = st.pop()
                for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    nx, ny = (x + dx, y + dy)
                    if 0 <= nx < n and 0 <= ny < n and (g[nx][ny] == '1'):
                        g[nx][ny] = '0'
                        st.append((nx, ny))
    print(answer)
T = int(input())
```

```python
def solve_case():
    n = int(input())
    a = list(map(int, input().split()))
    h = [0]
    for x in a:
        h.append(x)
        i = len(h) - 1
        while i > 1 and h[i] < h[i // 2]:
            h[i], h[i // 2] = (h[i // 2], h[i])
            i //= 2
    answer = 0
    i = n // 2
    while i:
        answer += h[i]
        i //= 2
    print(answer)
T = int(input())
```

```python
def solve_case():
    n = int(input())
    g = [list(map(int, input().split())) for _ in range(n)]
    for r in range(n):
        for c in range(n):
            if r == 0 and c == 0:
                continue
            best = 10 ** 9
            if r:
                best = min(best, g[r - 1][c])
            if c:
                best = min(best, g[r][c - 1])
            g[r][c] += best
```

```python
    def dfs(r, c, s):
        if len(s) == 4:
            found.add(s)
            return
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = (r + dr, c + dc)
            if 0 <= nr < 3 and 0 <= nc < 3:
                dfs(nr, nc, s + g[nr][nc])
    for r in range(3):
        for c in range(3):
            dfs(r, c, g[r][c])
    print(len(found))
```

```python
    def search(target):
        l, r = (1, p)
```

```python
def solve_case():
    n = int(input())
    g = [input().strip() for _ in range(n)]
    q = [(0, 0, 0)]
    seen = {(0, 0)}
    head = 0
    answer = -1
    while head < len(q):
        r, c, d = q[head]
        head += 1
        if (r, c) == (n - 1, n - 1):
            answer = d
            break
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = (r + dr, c + dc)
            if 0 <= nr < n and 0 <= nc < n and (g[nr][nc] == '0') and ((nr, nc) not in seen):
                seen.add((nr, nc))
                q.append((nr, nc, d + 1))
    print(answer)
```

# FA-L4 · 모범 풀이

```python
def solve_case():
    import heapq
    n, m = map(int, input().split())
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        g[u].append((v, w))
    d = [10 ** 9] * (n + 1)
    d[1] = 0
    q = [(0, 1)]
    while q:
        cost, u = heapq.heappop(q)
        if cost != d[u]:
            continue
        for v, w in g[u]:
            candidate = cost + w
            if candidate < d[v]:
                d[v] = candidate
                heapq.heappush(q, (candidate, v))
    print(*d[2:])
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
```

```python
def solve_case():
    import heapq
    n, m = map(int, input().split())
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        g[u].append((v, w))
        g[v].append((u, w))
    d = [10 ** 9] * (n + 1)
    d[1] = 0
    q = [(0, 1)]
    while q:
        cost, u = heapq.heappop(q)
        if cost != d[u]:
            continue
        for v, w in g[u]:
            candidate = max(cost, w)
            if candidate < d[v]:
                d[v] = candidate
                heapq.heappush(q, (candidate, v))
    print(*d[2:])
```

## 문제 유형 공개

## 핵심 구조 공개

정확히 K개를 고른 합을 S, 전체 합을 TOTAL이라고 하면 차이는 abs(S - (TOTAL - S))입니다. K개를 고르는 모든 조합을 확인하세요.

# FB-L5 · 모범 풀이

```python
def solve_case():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    total = sum(a)
    answers = []

    def dfs(i, count, load):
        if count == k:
            answers.append(abs(total - 2 * load))
            return
        if i >= n or count + n - i < k:
            return
        dfs(i + 1, count, load)
        dfs(i + 1, count + 1, load + a[i])
    dfs(0, 0, 0)
    print(min(answers))
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```
