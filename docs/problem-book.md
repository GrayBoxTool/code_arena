# S1-L1 · 지그재그 숫자

## 문제 설명

1부터 N까지 차례대로 계산합니다. 홀수는 더하고 짝수는 뺍니다.  
  
예를 들어 N이 5이면 1 - 2 + 3 - 4 + 5입니다. 계산한 최종 값을 구하세요.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
한 줄에 자연수 N이 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 10

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
최종 계산 결과를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
5
6
```

## 예제 출력

```text
#1 3
#2 -3
```

## 예제 해설

첫 번째는 3, 두 번째는 -3입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.

# S1-L2 · 날짜 계산기

```python
def solve_case():

T = int(input())

    solve_case()
```

```python
def solve_case():
    n,m=map(int,input().split())
    g=[input().strip() for _ in range(n)]
    p=[[0] for _ in range(3)]
    for row in g:
        for i,c in enumerate("WBR"): p[i].append(p[i][-1]+m-row.count(c))
    print(min(p[0][a]+p[1][b]-p[1][a]+p[2][n]-p[2][b] for a in range(1,n-1) for b in range(a+1,n)))
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
```

N개의 정수를 작은 수부터 큰 수 순서로 정렬하세요.  
  
같은 수가 여러 번 주어지면 그 개수만큼 모두 출력합니다. 입력에서 같은 값이 나왔다는 이유로 제거하지 않습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 N, 다음 줄에 정수 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 5 ≤ N ≤ 50
- 값은 정수입니다. 정렬 결과만으로 판단하며 별도의 값 크기 제한은 두지 않습니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
정렬한 N개 정수를 공백 한 칸으로 구분해 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
5
1 4 7 8 0
5
3 3 -1 0 3
```

## 예제 출력

```text
#1 0 1 4 7 8
#2 -1 0 3 3 3
```

## 예제 해설

첫 번째는 0 1 4 7 8입니다.  
두 번째는 -1 0 3 3 3이며, 3을 세 번 출력합니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.

# S3-L4 · 모범 풀이

```python
def solve_case():
    n,m=map(int,input().split())
    p=set()
    for _ in range(n):
        s=input().strip()
        for i in range(1,len(s)+1): p.add(s[:i])
    print(sum(input().strip() in p for _ in range(m)))
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

# S3-L5 · 모범 풀이

```python
def solve_case():
    n,b=map(int,input().split())
    a=list(map(int,input().split()))
    bits=1
    for x in a: bits|=bits<<x
    v=bits>>b
    print((v&-v).bit_length()-1)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```

```python
def solve_case():
```

```python
    def coord(v):
        d=1
        while d*(d+1)//2<v: d+=1
        x=v-d*(d-1)//2
        return x,d+1-x
    x,y=coord(p)
    u,v=coord(q)
    x+=u; y+=v
    print((x+y-2)*(x+y-1)//2+x)
```

```python
def solve_case():
    n,c,k=map(int,input().split())
    d=[[-1]*(c+1) for _ in range(k+1)]
    d[0]=[0]*(c+1)
    for _ in range(n):
        w,v=map(int,input().split())
        for count in range(k,0,-1):
            for cap in range(c,w-1,-1):
                if d[count-1][cap-w]>=0: d[count][cap]=max(d[count][cap],d[count-1][cap-w]+v)
    print(d[k][c])
```

```python
def solve_case():
    n,m=map(int,input().split())
    g=[input().strip() for _ in range(n)]
    c=[list(map(int,input().split())) for _ in range(n)]
    p=[[0]*(n+1) for _ in range(4)]
    for color,ch in enumerate("WBRG"):
        for r in range(n): p[color][r+1]=p[color][r]+sum(c[r][j] for j in range(m) if g[r][j]!=ch)
    d=[[10**9]*(n+1) for _ in range(5)]
    d[0][0]=0
    for count in range(1,5):
        for end in range(count,n+1):
            d[count][end]=min(d[count-1][start]+p[count-1][end]-p[count-1][start] for start in range(count-1,end))
    print(d[4][n])
T = int(input())
```

```python
def solve_case():
    n,l,r,target=input().split()
    n,l,r=int(n),int(l),int(r)
    start=1
    ans=0
    for _ in range(n):
        c,k=input().split(); k=int(k)
        end=start+k-1
        if c==target: ans+=max(0,min(r,end)-max(l,start)+1)
        start=end+1
    print(ans)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
```

```python
def solve_case():
    n,k,b=map(int,input().split())
    a=list(map(int,input().split()))
    d=[set() for _ in range(k+1)]
    d[0].add(0)
    for x in a:
        for count in range(k,0,-1): d[count].update(s+x for s in d[count-1])
    possible=[s-b for s in d[k] if s>=b]
    print(min(possible) if possible else -1)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
```

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
B 이상인 최소 출력 합에서 B를 뺀 값을 출력합니다. 불가능하면 -1입니다.

```text

```


## 예제 해설

첫 번째는 1번과 3번을 선택한 합 9가 최소이므로 차이 2입니다.

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.

# FB-L5 · 모범 풀이

```python
def solve_case():
    n,b=map(int,input().split())
    a=list(map(int,input().split()))
    def reachable(values):
        skip,take=1,0
        for x in values: skip,take=skip|take,skip<<x
        return skip|take
    bits=reachable(a[1:]) | (reachable(a[2:-1])<<a[0])
    v=bits>>b
    print((v&-v).bit_length()-1 if v else -1)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```
