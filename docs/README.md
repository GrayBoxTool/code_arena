# 문제 파일 안내

총 35문제입니다. 럼블은 5라운드 × 5문제, 결승은 A팀과 B팀에 각각 다른 5문제를 제공합니다.

| 폴더·파일 | 내용 |
|---|---|
| `questions/` | 문제별 지문, 제약조건, 입력·출력 형식, 예제와 해설 |
| `answers/` | SWEA 형식으로 바로 실행할 수 있는 모범 풀이 |
| `hints/` | 문제 유형 공개와 핵심 구조 공개 문구 |
| `tests/` | 문제별 공개·비공개 채점 입력과 기대 출력 |
| `problem-book.md` | 문제, 힌트, 정답을 모은 운영자용 책자 |
| `test-cases.json` | 전체 문제의 테스트 모음 |

파일 이름은 문제 ID입니다. 예를 들어 `S2-L3`은 럼블 2라운드 레벨 3, `FA-L4`는 결승 A팀 레벨 4입니다.

결승의 팀 전용 Lv4/Lv5 추가 테스트는 경기 시작 시 서버가 별도로 만듭니다. 고정 테스트 파일에는 해당 경기의 비공개 추가 데이터가 포함되지 않습니다.

문서만 수정해도 서버 문제가 바뀌지는 않습니다. 서버 원본은 `problem_texts.py`(럼블 지문), `bank_v2.py`와 `problems.py`(럼블 풀이·케이스), `final_bank.py`(결승 전체)입니다. 원본 변경 후 프로젝트 폴더에서 `python export_problem_files.py`를 실행하면 이 폴더의 문서를 다시 만듭니다.

이 폴더에는 정답과 숨은 테스트가 있습니다. Netlify에는 `static/`만 공개하세요.
