# 문제 파일 안내

총 35문제입니다. 럼블은 5라운드 × 5문제, 결승은 A팀과 B팀에 각각 다른 5문제를 제공합니다.

| 폴더·파일 | 내용 |
|---|---|
| `questions/` | 문제별 지문, 제약조건, 입력·출력 형식, 예제와 필요한 그림 |
| `answers/` | SWEA 형식으로 바로 실행할 수 있는 모범 풀이 |
| `hints/` | 문제 유형 공개와 핵심 구조 공개 문구 |
| `tests/` | 문제별 공개·비공개 채점 입력과 기대 출력 |
| `problem-book.md` | 문제, 힌트, 정답을 모은 운영자용 책자 |
| `test-cases.json` | 전체 문제의 테스트 모음 |

파일 이름은 문제 ID입니다. 예를 들어 `S2-L3`은 럼블 2라운드 레벨 3, `FA-L4`는 결승 A팀 레벨 4입니다.

결승 Lv4/Lv5 연계 입력은 사용하지 않습니다. 각 문제를 독립적으로 채점하며 경기 종료 때 결승 승점 합으로 승패를 정합니다.

25개 원본 문제의 레벨 배정과 검토 내용은 `source-check.md`를 확인하세요. 결승은 두 팀에 서로 다른 문제를 제공하며 동일 레벨에 동일 승점을 지급합니다. 승점 동점은 남은 solve 잔액으로 판정하고, 잔액도 같으면 무승부입니다.

서버 원본은 `rumble_bank.py`(럼블 전체), `final_bank.py`(결승 전체), `problems.py`(공통 형식·예제 생략), `source_cases.json`(원본 예제 검증)입니다. 원본 변경 후 `python export_problem_files.py`를 실행하면 문서를 다시 만듭니다. 게임 및 지문 문서에는 생략된 예제만 표시하지만, 운영자 전용 tests에는 실행 가능한 전체 채점 데이터가 있습니다.

이 폴더에는 정답과 숨은 테스트가 있습니다. Netlify에는 `static/`만 공개하세요.

문제 그림은 `../static/problem-images/`에 보관하며 개별 문제 문서와 통합 문제집 모두 상대 경로로 연결합니다. 원본의 그림 11장과 결승 설명용 도식 4장을 포함합니다. 입력 형식 별도 구역과 예제 해설 구역은 표시하지 않습니다.
