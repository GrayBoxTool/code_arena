## 원본 정리와 검증
- ‘사각 덧셈’은 본문 의미에 맞게 ‘시각 덧셈’으로 표시했습니다.
- ‘평범한 숫자’의 순열 범위 오타를 1~N으로 바로잡았습니다.
- ‘날짜 계산기’ 원본 입력은 T=10 뒤에 12사례가 있습니다. 선언된 10사례만 원본 출력과 대조했고, 뒤의 두 줄은 원본 검증 자료에만 보관했습니다.
- 구독자 전쟁 원본의 보이지 않는 문자와 입력 파일의 BOM을 제거했습니다.
- 입력·출력 쌍이 있는 21문제를 원본 기대 출력과 대조했습니다. 나머지 네 문제는 본문 규칙에 맞춘 예제와 테스트를 만들었습니다.
- 긴 공개 예제는 두 사례의 일부를 각각 보존하고 최대 10줄로 표시합니다. 생략 표시를 실제 입력으로 사용하면 안 됩니다.
- 첫 두 사례가 공개 예제이며 이후 사례는 경계값·반복값·무작위 입력 및 제공된 원본 예제입니다. 원본 예제는 공개 자료이므로 숨은 사례만의 보안 자료로 간주하지 않습니다.
- 결승 Lv4·5는 별도의 작은 입력 전수 탐색으로 모범 풀이를 교차 검증했습니다.

## 결승 난도 구성
Lv1은 여러 값의 비용 누적·선택, Lv2는 조건부 문자열 삭제·압축 구간 계산, Lv3는 접두어 빈도·구간 누적, Lv4는 선택 개수가 고정된 최적화, Lv5는 다중 구간·원형 제약 최적화입니다. 10분 기준으로 작성했으며 팀별 경험에 따른 체감 난도는 리허설에서 확인하세요.
