# S2-L1 · 첫 중복 신호

## 문제 설명

정수 신호 N개를 입력된 순서대로 하나씩 확인합니다. 이전에 등장했던 값이 다시 나오는 순간, 해당 신호를 중복 신호로 판단합니다.  
  
처음으로 중복 판정을 받는 신호 값을 구하세요. 여러 번 등장하는 값 중 가장 작은 값을 찾는 문제가 아니라, 왼쪽부터 확인했을 때 가장 먼저 다시 등장하는 값을 찾는 문제입니다.  
  
끝까지 확인해도 다시 등장하는 값이 없으면 -1을 출력합니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 신호 개수 N이 주어집니다.  
다음 줄에 정수 신호 N개가 확인할 순서대로 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 100
- 0 ≤ 각 신호 값 ≤ 1000

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
가장 먼저 다시 등장한 값 하나를 출력합니다. 없다면 -1입니다.

```text
#tc answer
```

## 예제 입력

```text
2
5
9 8 7 8 9
4
1 2 3 4
```

## 예제 출력

```text
#1 8
#2 -1
```

## 예제 해설

첫 번째는 네 번째 신호 8에서 처음 중복이 발생합니다. 뒤에 나오는 9보다 8을 먼저 출력해야 합니다.  
두 번째는 모든 값이 다르므로 -1입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
