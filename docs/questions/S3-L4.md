# S3-L4 · 접두어 검색

## 문제 설명

문자열의 첫 글자부터 연속해서 가져온 문자열을 접두어라고 합니다. 단어 전체도 자신의 접두어입니다.  
  
그룹 B의 각 단어에 대해, 그룹 A의 단어 중 하나 이상의 접두어인지 확인하세요. 조건을 만족하는 B 단어의 수를 구합니다.  
  
B의 단어 하나가 A의 여러 단어에 해당해도 한 번만 셉니다. B에 같은 단어가 여러 줄로 주어지면 각 줄을 별도로 셉니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 A와 B의 단어 수 N, M이 주어집니다.  
이후 N줄에 A 단어, 다음 M줄에 B 단어가 하나씩 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N M
A의 단어 N줄
B의 단어 M줄
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 3 ≤ N, M ≤ 3000
- 각 단어는 길이 1~20의 영문 소문자 문자열입니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
A 단어의 접두어인 B 단어의 개수를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
3 3
able
… (중간 줄 생략) …
a
3 3
cat
dog
… (중간 줄 생략) …
x
```

## 예제 출력

```text
#1 2
#2 2
```

## 예제 해설

첫 번째는 ab와 a가 해당하므로 2입니다. abo는 A 단어의 접두어가 아닙니다.  
두 번째는 ca와 dog가 해당하므로 2입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
