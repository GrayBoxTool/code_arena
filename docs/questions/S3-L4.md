# S3-L4 · 병력 합치기

## 문제 설명

병력 묶음 N개를 정해진 규칙에 따라 합칩니다. 한 번의 작업에서는 현재 남아 있는 묶음 중 크기가 가장 작은 두 개를 골라 하나로 합칩니다.  
  
합친 새 묶음의 크기만큼 비용이 발생합니다. 새 묶음은 다시 후보에 포함되므로, 이후 작업에서 다시 선택될 수 있습니다. 같은 크기의 묶음끼리는 어느 것을 골라도 됩니다.  
  
이 작업을 정확히 K번 수행할 때 발생하는 비용의 합을 구하세요. K가 0이면 작업을 하지 않으므로 비용은 0입니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 처음 묶음 수 N과 합칠 횟수 K가 주어집니다.  
다음 줄에 각 묶음의 크기 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N K
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 2 ≤ N ≤ 12
- 0 ≤ K < N
- 1 ≤ 처음 묶음의 크기 ≤ 30

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
K번 작업에서 발생한 비용의 총합을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
4 2
1 2 3 8
3 0
1 2 3
```

## 예제 출력

```text
#1 9
#2 0
```

## 예제 해설

첫 번째는 1과 2를 합쳐 비용 3이 발생합니다. 남은 크기는 3, 3, 8이며, 다음에 3과 3을 합쳐 비용 6이 발생합니다. 총비용은 9입니다.  
두 번째는 작업을 하지 않으므로 0입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
