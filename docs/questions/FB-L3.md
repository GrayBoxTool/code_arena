# FB-L3 · 에너지 트리의 합산

## 문제 설명

노드 번호가 1부터 N까지인 완전 이진 트리에 에너지 저장소가 있습니다. 노드 i의 왼쪽 자식은 2 × i, 오른쪽 자식은 2 × i + 1입니다. N보다 큰 번호의 자식은 존재하지 않습니다.  
  
각 노드에는 자신의 에너지 양이 저장되어 있습니다. 한 노드의 합산 에너지는 그 노드 자신과 모든 자손 노드의 에너지를 더한 값입니다.  
  
루트인 1번 노드의 합산 에너지와 K번 노드의 합산 에너지를 구하세요. 조상이나 형제 노드의 에너지는 K번 노드의 합산에 포함하지 않습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
각 테스트케이스의 첫 줄에 N과 K가 주어집니다.  
다음 줄에는 1번부터 N번 노드까지 각 노드 자신의 에너지 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N K
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ K ≤ N ≤ 500
- 각 노드의 에너지는 0 이상 100 이하의 정수입니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
1번 노드의 합산 에너지와 K번 노드의 합산 에너지를 공백 한 칸으로 구분해 출력합니다.

```text
#tc root_value node_value
```

## 예제 입력

```text
2
5 2
3 2 4 5 1
1 1
7
```

## 예제 출력

```text
#1 15 8
#2 7 7
```

## 예제 해설

첫 번째에서 루트는 모든 노드의 에너지 3 + 2 + 4 + 5 + 1 = 15를 모읍니다. 노드 2의 자손은 4, 5번이므로 2 + 5 + 1 = 8입니다.  
두 번째는 두 출력 대상이 같은 노드이므로 7 7입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
