# S1-L4 · 작업 시간표

## 문제 설명

하나의 작업실에서 처리할 수 있는 작업 N개가 있습니다. 각 작업에는 시작 시각과 종료 시각이 정해져 있으며, 선택한 작업의 시각을 바꿀 수는 없습니다.  
  
작업실은 동시에 하나의 작업만 수행할 수 있습니다. 한 작업이 끝나는 시각과 다른 작업이 시작하는 시각이 같으면 두 작업을 이어서 수행할 수 있습니다.  
  
작업 일부를 골라 서로 겹치지 않게 수행할 때, 수행할 수 있는 작업 수의 최댓값을 구하세요. 입력은 시간순으로 정렬되어 있지 않을 수 있습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 작업 수 N이 주어집니다.  
다음 N줄에 각 작업의 시작 시각 s와 종료 시각 e가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N
s1 e1
s2 e2
...
sN eN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 12
- 0 ≤ s < e ≤ 30
- 같은 시간 구간의 작업이 여러 개 있을 수 있습니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
겹치지 않게 수행할 수 있는 최대 작업 수를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
4
0 2
2 4
1 5
4 6
3
1 4
1 4
1 4
```

## 예제 출력

```text
#1 3
#2 1
```

## 예제 해설

첫 번째는 [0, 2], [2, 4], [4, 6]의 세 작업을 수행할 수 있습니다.  
두 번째는 모든 작업이 같은 시간에 겹치므로 하나만 수행할 수 있습니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
