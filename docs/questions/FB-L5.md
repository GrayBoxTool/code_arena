# FB-L5 · 두 전원 장치의 부하 균형

## 문제 설명

N개 중계소에 필요한 출력이 각각 주어집니다. 모든 중계소를 전원 장치 A 또는 B 중 하나에 연결하려고 합니다. 한 중계소를 두 장치에 동시에 연결하거나 어느 쪽에도 연결하지 않는 것은 허용하지 않습니다.  
  
배선 규칙에 따라 정확히 K개 중계소를 장치 A에 연결하고, 나머지 N - K개를 장치 B에 연결해야 합니다. 각 장치의 부하는 그 장치에 연결된 중계소의 출력 합입니다.  
  
두 장치의 부하 차이의 절댓값을 최소화하세요. 중계소의 순서는 선택을 제한하지 않습니다. 출력이 같아도 서로 다른 번호의 중계소입니다.  
  
[Lv4와의 연결 및 채점]  
문제의 규칙과 예제만으로 코드를 작성하고, Lv4를 풀기 전에도 제출할 수 있습니다. 처음부터 일반 테스트와 팀 전용 추가 테스트를 함께 채점합니다.  
  
팀 전용 테스트의 수열은 Lv4 팀 전용 입력의 정답 출력에서 가져옵니다. Lv4 정답 후에는 이 수열과 N, K가 화면에 공개되어, 실제 값으로 풀이를 검산할 수 있습니다. 공개 전후에 채점 데이터나 규칙이 바뀌지는 않습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
각 테스트케이스의 첫 줄에 중계소 수 N과 장치 A에 연결할 개수 K가 주어집니다.  
다음 줄에 1번부터 N번까지 각 중계소에 필요한 출력 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N K
p1 p2 ... pN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 4 ≤ N ≤ 15
- 1 ≤ K < N
- 각 출력은 1 이상 450 이하의 정수입니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
두 장치의 부하 차이의 절댓값 중 최솟값을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
5 2
2 3 4 5 6
4 1
7 7 7 7
```

## 예제 출력

```text
#1 0
#2 14
```

## 예제 해설

첫 번째는 출력 4와 6을 장치 A에 연결하면 A의 부하는 10, B도 10이므로 차이는 0입니다.  
두 번째는 A에 하나만 연결해야 합니다. A는 7, B는 21이므로 차이는 14입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
