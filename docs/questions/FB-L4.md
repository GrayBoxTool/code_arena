# FB-L4 · 정확한 인원의 구조대

## 문제 설명

N명의 후보에게 각각 구조 능력치가 있습니다. 정확히 K명을 골라 능력치 합이 목표 B 이상인 구조대를 구성하려고 합니다.  
  
후보 한 명을 여러 번 고를 수 없고, 능력치가 같아도 후보 번호가 다르면 다른 사람입니다.  
  
조건을 만족하는 합 중 가장 작은 합을 골라 B와의 차이를 출력하세요. 정확히 K명을 골라서는 목표에 도달할 수 없다면 -1을 출력합니다.



## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 설명에 따라 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 N, K, B, 다음 줄에 후보 능력치 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

## 제약조건

- 1 ≤ N ≤ 30
- 1 ≤ K ≤ min(N,10)
- 1 ≤ ai ≤ 50
- 1 ≤ B ≤ 1500

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
목표를 넘는 양의 최솟값을 출력합니다. 정확히 목표면 0, 불가능하면 -1입니다.

```text
#tc answer
```

## 예제 입력

```text
2
4 2 10
3 5 6 8
3 1 20
5 6 7
```

## 예제 출력

```text
#1 1
#2 -1
```

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
