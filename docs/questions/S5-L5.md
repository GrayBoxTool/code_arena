# S5-L5 · 세 장의 암호 카드

## 문제 설명

N장의 카드에는 각각 양의 정수가 적혀 있습니다. 이 중 서로 다른 카드 정확히 세 장을 골라 숫자의 합을 만들려고 합니다.  
  
합이 V 이하인 선택 중 가장 큰 합을 구하세요. 카드 세 장을 반드시 골라야 하며, 한 카드를 여러 번 사용할 수는 없습니다.  
  
같은 숫자가 적힌 카드도 서로 다른 위치에 있다면 별개의 카드입니다. 어떤 세 장을 골라도 합이 V를 넘는다면 -1을 출력합니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 카드 수 N과 합의 상한 V가 주어집니다.  
다음 줄에 카드 값 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N V
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 3 ≤ N ≤ 40
- 0 ≤ V ≤ 300
- 1 ≤ 각 카드 값 ≤ 100

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
세 카드의 합 중 V 이하인 최댓값을 출력합니다. 조건을 만족할 수 없다면 -1입니다.

```text
#tc answer
```

## 예제 입력

```text
2
5 21
5 6 7 8 9
3 2
1 1 1
```

## 예제 출력

```text
#1 21
#2 -1
```

## 예제 해설

첫 번째는 5, 7, 9 등으로 합 21을 만들 수 있습니다.  
두 번째는 세 장의 합이 3이어서 상한 2를 넘으므로 -1입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
