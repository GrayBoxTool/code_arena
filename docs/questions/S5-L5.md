# S5-L5 · 해피박스

## 문제 설명

용량 N의 상자에 물건을 골라 담습니다. 물건 i의 크기는 Si, 가격은 Pi이고, 각 물건은 하나씩만 있습니다.  
  
선택한 물건의 크기 합이 N 이하여야 합니다. 상자를 빈틈없이 채울 필요는 없으며, 물건을 나누어 담을 수는 없습니다.  
  
조건을 만족하는 선택 중 가격 합의 최댓값을 구하세요. 같은 크기와 가격의 물건도 번호가 다르면 다른 물건입니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 상자 용량 N과 물건 수 M, 다음 M줄에 크기 Si와 가격 Pi가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N M
S1 P1
...
SM PM
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 10 ≤ N ≤ 100
- 1 ≤ M, Si, Pi ≤ 20

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
담을 수 있는 최대 가격 합을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
10 3
6 10
4 12
5 13
10 1
11 20
```

## 예제 출력

```text
#1 25
#2 0
```

## 예제 해설

첫 번째는 2번과 3번을 골라 크기 9, 가격 25입니다.  
두 번째 물건은 상자보다 커서 담을 수 없으므로 0입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
