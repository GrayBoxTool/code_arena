# S5-L2 · 단축키 입력

## 문제 설명

목표 문자열 A를 처음부터 끝까지 입력하려고 합니다. 한 번의 키 입력으로 문자 한 글자를 입력하거나, 미리 저장된 문자열 B 전체를 입력할 수 있습니다.  
  
입력한 문자열의 뒤에만 내용을 붙일 수 있습니다. 이미 입력한 문자를 지우거나 바꿀 수 없고, 목표 문자열 뒤에 불필요한 문자를 추가해서도 안 됩니다.  
  
A를 정확히 완성하는 데 필요한 최소 키 입력 횟수를 구하세요. B 전체를 입력하는 것도 한 번으로 셉니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
각 테스트케이스마다 한 줄에 목표 문자열 A와 단축키 문자열 B가 공백 한 칸으로 구분되어 주어집니다.  
두 문자열 내부에는 공백이 없습니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
A B
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ A의 길이 ≤ 100
- 1 ≤ B의 길이 ≤ 10
- 두 문자열은 대문자 A와 B로만 이루어집니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
필요한 최소 키 입력 횟수를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
ABABA AB
AAA AA
```

## 예제 출력

```text
#1 3
#2 2
```

## 예제 해설

첫 번째는 단축키 AB를 두 번 사용하고 A를 한 번 입력하면 총 3회입니다.  
두 번째는 AA 한 번과 A 한 번으로 총 2회입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
