# FA-L2 · K개씩 사라지는 신호

## 문제 설명

문자열을 왼쪽부터 한 글자씩 읽어 신호를 쌓습니다. 같은 문자가 연속하여 정확히 K개가 쌓이는 순간 그 K개를 모두 없앱니다.  
  
제거 후 이어진 부분에도 같은 규칙이 적용됩니다. 새 글자를 읽을 때마다 제거를 처리합니다. 모든 문자를 처리한 뒤 남은 문자열의 길이를 구하세요.  
  
원래 문제의 두 글자 제거를 일반화한 것으로, K보다 적게 남은 같은 문자는 제거하지 않습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 제거 기준 K, 다음 줄에 공백 없는 대문자 문자열 S가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
K
S
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 2 ≤ K ≤ 10
- 1 ≤ 문자열 길이 ≤ 3000

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
남은 문자열의 길이를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
3
ABBBAA
2
ABBA
```

## 예제 출력

```text
#1 0
#2 0
```

## 예제 해설

첫 번째는 BBB가 지워진 뒤 AAA도 지워져 0입니다.  
두 번째는 BB와 AA가 지워져 0입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
