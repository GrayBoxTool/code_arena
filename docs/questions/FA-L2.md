# FA-L2 · 격납고 탈출 경로

## 문제 설명

N × N 격납고에서 왼쪽 위 칸을 출발해 오른쪽 아래 칸으로 이동하려고 합니다. 지도에서 0은 이동 가능한 칸, 1은 막힌 칸입니다.  
  
한 번에 위, 아래, 왼쪽, 오른쪽 중 한 방향으로 정확히 한 칸 이동할 수 있습니다. 대각선 이동과 지도 밖으로 나가는 이동은 허용하지 않습니다.  
  
출발 칸에 서 있는 상태는 이동 횟수에 포함하지 않습니다. 도착 칸까지 필요한 최소 이동 횟수를 구하고, 도달할 수 없으면 -1을 출력하세요.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
각 테스트케이스의 첫 줄에 N이 주어집니다.  
다음 N줄에는 지도 한 행을 나타내는 길이 N의 문자열이 주어집니다. 각 행 안에는 공백이 없습니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N
row1
row2
...
rowN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 2 ≤ N ≤ 10
- 지도에는 0과 1만 등장합니다.
- 출발 칸과 도착 칸은 항상 0입니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
최소 이동 횟수를 출력합니다. 도달할 수 없다면 -1을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
3
000
110
000
2
01
10
```

## 예제 출력

```text
#1 4
#2 -1
```

## 예제 해설

첫 번째는 오른쪽으로 두 번, 아래로 두 번 이동하면 도착하므로 4입니다.  
두 번째는 출발 칸의 오른쪽과 아래쪽이 모두 막혀 있어 -1입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
