# S4-L4 · 최소 힙의 조상

## 문제 설명

빈 최소 힙에 N개의 정수를 입력된 순서대로 삽입합니다. 힙의 배열 인덱스는 1부터 시작하며, 노드 i의 부모는 i // 2입니다.  
  
삽입할 때에는 새 값을 배열의 마지막 위치에 넣습니다. 그 값이 부모 값보다 작으면 서로 교환하고, 부모 위치에서 같은 검사를 반복합니다. 값이 같으면 교환하지 않습니다.  
  
모든 값을 삽입한 뒤, 배열의 N번 위치에 있는 노드의 조상 값들을 더하세요. N번 노드 자신의 값은 합에 넣지 않습니다. 마지막에 입력한 값이 아니라 삽입 완료 후 N번 위치를 기준으로 합니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 삽입할 값의 개수 N이 주어집니다.  
다음 줄에 삽입 순서대로 정수 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 100
- 1 ≤ 각 값 ≤ 1000
- 같은 값이 여러 번 주어질 수 있습니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
N번 노드의 모든 조상 값의 합을 출력합니다. N이 1이면 0입니다.

```text
#tc answer
```

## 예제 입력

```text
2
5
7 2 5 1 3
1
9
```

## 예제 출력

```text
#1 3
#2 0
```

## 예제 해설

첫 번째에서 삽입 완료 후 힙 배열은 1, 2, 5, 7, 3입니다. 5번 노드의 조상은 2번과 1번이므로 합은 2 + 1 = 3입니다.  
두 번째는 루트만 있어 조상이 없으므로 0입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
