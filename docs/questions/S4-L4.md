# S4-L4 · 수의 새로운 연산

## 문제 설명

격자점 (x, y)에 대각선 순서로 번호를 붙입니다. x와 y는 1부터 시작합니다.  
  
x + y가 작은 대각선부터 번호를 붙이며, 같은 대각선에서는 x가 작은 점부터 붙입니다. 예를 들어 (1,1)=1, (1,2)=2, (2,1)=3, (1,3)=4, (2,2)=5, (3,1)=6입니다.  
  
두 번호 p와 q를 각각 좌표로 바꾼 뒤 x끼리, y끼리 더합니다. 합친 좌표에 붙은 번호를 구하세요.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
한 줄에 두 번호 p와 q가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
p q
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ p, q ≤ 10000
- 결과 번호는 10000을 넘을 수 있습니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
합친 좌표의 번호를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
1 5
3 3
```

## 예제 출력

```text
#1 13
#2 14
```

## 예제 해설

첫 번째는 (1,1)+(2,2)=(3,3)이고 번호는 13입니다.  
두 번째는 (2,1)+(2,1)=(4,2)이고 번호는 14입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
