# S5-L3 · 현주의 상자 바꾸기

## 문제 설명

1번부터 N번까지 상자의 값은 처음에 모두 0입니다. Q개의 작업을 순서대로 수행합니다.  
  
i번째 작업에서는 L번부터 R번까지 양 끝을 포함한 모든 상자의 값을 i로 바꿉니다. 이전 값에 i를 더하는 것이 아니라 덮어씁니다.  
  
모든 작업을 마친 뒤 상자 값을 번호순으로 출력하세요.



## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 설명에 따라 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 N과 Q, 다음 Q줄에 변경할 범위 L, R이 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

## 제약조건

- 1 ≤ N, Q ≤ 1000
- 1 ≤ L ≤ R ≤ N

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
1번부터 N번까지의 값을 공백으로 구분해 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
5 2
1 3
2 4
3 1
2 2
```

## 예제 출력

```text
#1 1 2 2 2 0
#2 0 1 0
```

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
