# S4-L2 · 사라지는 문자 쌍

## 문제 설명

문자열을 왼쪽부터 한 글자씩 읽으며 새로운 문자열을 만듭니다. 처음에 새 문자열은 비어 있습니다.  
  
새로 읽은 글자가 현재 남아 있는 문자열의 마지막 글자와 같으면, 마지막 글자와 새 글자를 함께 없앱니다. 다르면 새 글자를 끝에 붙입니다. 남은 문자열이 비어 있을 때에는 새 글자를 그대로 붙입니다.  
  
모든 글자를 처리한 뒤 남은 문자열의 길이를 구하세요. 앞선 삭제 결과로 서로 만나게 된 글자들도 같은 규칙에 따라 없어질 수 있습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
각 테스트케이스마다 문자열 S가 한 줄에 주어집니다. 문자열 안에는 공백이 없습니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
S
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ 문자열 길이 ≤ 100
- 문자열은 대문자 A, B, C로만 이루어집니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
최종 문자열의 길이를 출력합니다. 모두 사라지면 0입니다.

```text
#tc answer
```

## 예제 입력

```text
2
ABBA
ABCA
```

## 예제 출력

```text
#1 0
#2 4
```

## 예제 해설

첫 번째는 가운데 BB가 사라진 뒤 AA도 사라져 길이가 0입니다.  
두 번째는 처리 중 같은 글자가 맞닿지 않으므로 길이는 4입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
