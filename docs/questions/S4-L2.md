# S4-L2 · 간단한 압축 풀기

## 문제 설명

압축된 문서는 문자와 반복 횟수의 쌍으로 주어집니다. 각 문자를 지정한 횟수만큼 반복해 입력 순서대로 이어 붙이세요.  
  
완성된 문자열을 앞에서부터 한 줄에 10글자씩 출력합니다. 마지막 줄에 10글자가 남지 않았다면 남은 글자만 출력합니다. 문자 쌍이 바뀌어도 줄을 새로 시작하지 않습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 문자 쌍 수 N, 다음 N줄에 대문자 C와 반복 횟수 K가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N
C1 K1
...
CN KN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 10
- A ≤ C ≤ Z
- 1 ≤ K ≤ 20

## 출력

각 테스트케이스의 첫 줄에 #과 번호를 붙여 출력합니다. 예: #1  
다음 줄부터 복원한 문자열을 10글자씩 줄을 바꾸어 출력합니다. 마지막 줄은 10글자보다 짧을 수 있습니다.  
  
먼저 #tc만 한 줄에 출력합니다. 다음 줄부터 복원 문서를 10글자씩 출력합니다. 테스트케이스 사이 빈 줄은 없습니다.

```text
#tc
결과 문자열을 10글자씩 출력
```

## 예제 입력

```text
2
3
A 10
B 7
C 5
1
Z 3
```

## 예제 출력

```text
#1
AAAAAAAAAA
BBBBBBBCCC
CC
#2
ZZZ
```

## 예제 해설

첫 번째는 A 10개, B 7개, C 5개를 이어 붙여 10글자·10글자·2글자의 세 줄로 출력합니다.  
두 번째는 ZZZ 한 줄입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
