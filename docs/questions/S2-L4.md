# S2-L4 · 교환권 최소 사용

## 문제 설명

서로 다른 가치의 교환권 N종류가 있습니다. 각 종류의 교환권은 필요한 만큼 사용할 수 있습니다.  
  
교환권 가치의 합을 정확히 V로 만들려고 합니다. 이때 필요한 교환권 장수의 최솟값을 구하세요. V보다 크거나 작은 합은 인정하지 않습니다.  
  
정확히 V를 만들 수 없으면 -1을 출력합니다. V가 0이면 교환권을 사용하지 않는 방법이 가능하므로 0을 출력합니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 교환권 종류 수 N과 목표 가치 V가 주어집니다.  
다음 줄에 N종류의 교환권 가치가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N V
c1 c2 ... cN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 6
- 0 ≤ V ≤ 50
- 1 ≤ 각 교환권 가치 ≤ 50
- 교환권 가치는 서로 다릅니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
필요한 최소 장수를 출력합니다. 불가능하면 -1입니다.

```text
#tc answer
```

## 예제 입력

```text
2
3 6
1 3 4
2 7
4 6
```

## 예제 출력

```text
#1 2
#2 -1
```

## 예제 해설

첫 번째는 가치 3인 교환권 두 장으로 6을 만들 수 있습니다. 가치 4부터 사용하는 방법보다 장수가 적습니다.  
두 번째는 4와 6을 어떤 개수로 사용해도 7을 만들 수 없습니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
