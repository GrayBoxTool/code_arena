# S2-L4 · 늘어지는 소리 만들기

## 문제 설명

원래 문자열의 지정된 위치에 하이픈(-)을 추가합니다. 위치 0은 첫 문자 앞이고, 위치 i는 원래 문자열의 i번째 문자 뒤입니다.  
  
위치는 하이픈을 넣기 전의 원래 문자열을 기준으로 합니다. 같은 위치가 여러 번 주어지면 그 개수만큼 하이픈을 넣습니다. 위치가 입력된 순서는 결과에 영향을 주지 않습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 소문자 문자열 S, 다음 줄에 하이픈 수 H, 그다음 줄에 삽입 위치 H개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
S
H
p1 p2 ... pH
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ 문자열 길이 L ≤ 20
- 1 ≤ H ≤ 100
- 0 ≤ 위치 ≤ L

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
하이픈을 모두 넣은 문자열을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
wow
3
2 3 2
hoi
3
0 0 0
```

## 예제 출력

```text
#1 wo--w-
#2 ---hoi
```

## 예제 해설

첫 번째는 wo--w-입니다. 두 번째는 맨 앞에 세 개를 넣어 ---hoi입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
