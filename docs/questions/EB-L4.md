# EB-L4 · 탈출에 필요한 이동

## 문제 설명

N × N 지도에서 왼쪽 위 칸 (1,1)부터 오른쪽 아래 칸 (N,N)까지 이동합니다. 0은 이동할 수 있는 칸, 1은 벽입니다.  
  
한 번에 상하좌우 인접한 칸으로만 이동합니다. 지도 밖으로 나갈 수 없습니다. 도착까지 필요한 최소 이동 횟수를 구하세요. 시작 칸은 이동 횟수에 포함하지 않습니다. 도달할 수 없으면 -1입니다.



## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 설명에 따라 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄 N. 다음 N줄에 0과 1로 된 길이 N 문자열. 행 안에는 공백이 없습니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

## 제약조건

- 1 ≤ N ≤ 30
- 시작과 도착 칸은 0

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
최소 이동 횟수 또는 -1을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
1
0
2
00
00
```

## 예제 출력

```text
#1 0
#2 2
```

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
