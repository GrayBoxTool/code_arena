# FA-L4 · 정확히 K개의 해피박스

## 문제 설명

용량 C인 상자에 N개 물건 중 정확히 K개를 넣으려고 합니다. 각 물건에는 크기와 가격이 있으며, 같은 물건을 두 번 선택할 수 없습니다.  
  
크기 합은 C 이하여야 합니다. 조건을 만족하는 선택 중 가격 합의 최댓값을 구하세요. 개수가 K보다 적거나 많으면 인정하지 않습니다.  
  
어떤 방법으로도 정확히 K개를 담을 수 없다면 -1을 출력합니다. K가 0이면 빈 선택이 가능하고 가격 합은 0입니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 N, C, K, 다음 N줄에 각 물건의 크기와 가격이 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N C K
크기 가격 (N줄)
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 30
- 1 ≤ C ≤ 100
- 0 ≤ K ≤ min(N,10)
- 1 ≤ 크기, 가격 ≤ 50

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
최대 가격 합을 출력합니다. 불가능하면 -1입니다.

```text
#tc answer
```

## 예제 입력

```text
2
3 10 2
6 10
4 12
5 13
2 5 2
3 8
4 9
```

## 예제 출력

```text
#1 25
#2 -1
```

## 예제 해설

첫 번째는 2번과 3번 물건을 담아 크기 9, 가격 25입니다.  
두 번째는 두 물건의 크기 합이 7이므로 -1입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
