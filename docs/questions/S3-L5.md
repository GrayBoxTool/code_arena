# S3-L5 · 목표 이상 보급

## 문제 설명

보급 상자 N개에는 각각 양의 정수로 된 보급량이 들어 있습니다. 각 상자는 통째로 사용하거나 사용하지 않을 수 있고, 같은 상자를 두 번 사용할 수는 없습니다.  
  
선택한 상자의 보급량 합이 V 이상이어야 합니다. 조건을 만족하는 합 중 가장 작은 값을 구하세요. 상자 개수 자체를 최소화하는 문제는 아닙니다.  
  
모든 상자를 골라도 V에 도달할 수 없다면 -1을 출력합니다. V가 0이면 아무 상자도 선택하지 않는 합 0이 정답입니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 상자 수 N과 필요한 최소 보급량 V가 주어집니다.  
다음 줄에 상자별 보급량 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N V
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 12
- 0 ≤ V ≤ 200
- 1 ≤ 각 보급량 ≤ 15

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
V 이상인 선택 합 중 최솟값을 출력합니다. 불가능하면 -1입니다.

```text
#tc answer
```

## 예제 입력

```text
2
4 10
3 5 6 8
2 20
4 7
```

## 예제 출력

```text
#1 11
#2 -1
```

## 예제 해설

첫 번째는 3과 8 또는 5와 6을 선택한 합 11이 조건을 만족하는 최소 합입니다.  
두 번째는 전체 합도 11이므로 -1입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
