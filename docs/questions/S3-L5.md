# S3-L5 · 장훈이의 높은 선반

## 문제 설명

N명의 점원 중 한 명 이상을 골라 탑을 만듭니다. 탑의 높이는 선택한 점원들의 키의 합이며, 각 점원은 최대 한 번만 선택할 수 있습니다.  
  
높이가 B 이상이어야 선반에 닿습니다. 가능한 탑 중 높이가 가장 낮은 탑을 고르고, 그 높이에서 B를 뺀 차이를 구하세요.  
  
모든 점원을 선택하면 B 이상이 되는 입력만 주어집니다.



## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 설명에 따라 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 N과 선반 높이 B, 다음 줄에 점원들의 키 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

## 제약조건

- 1 ≤ N ≤ 20
- 1 ≤ Hi ≤ 10000
- 1 ≤ B ≤ 모든 키의 합

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
B 이상인 최소 높이에서 B를 뺀 값을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
5 16
3 1 3 5 6
2 10
7 7
```

## 예제 출력

```text
#1 1
#2 4
```

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
