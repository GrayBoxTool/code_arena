# S2-L3 · 분리된 기지

## 문제 설명

1번부터 N번까지의 기지가 양방향 통로로 연결되어 있습니다. 한 통로로 연결된 기지끼리는 어느 방향으로든 이동할 수 있습니다.  
  
통로를 여러 번 거쳐서라도 서로 이동할 수 있는 기지들은 하나의 묶음에 속합니다. 전체 기지를 이러한 묶음으로 나누었을 때 묶음의 수를 구하세요.  
  
다른 기지와 연결된 통로가 전혀 없는 기지도 혼자 하나의 묶음을 이룹니다. 같은 통로가 여러 번 주어져도 연결 관계는 변하지 않습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 기지 수 N과 통로 수 M이 주어집니다.  
다음 M줄에 통로로 연결된 두 기지 u, v가 주어집니다. M이 0이면 통로 입력 줄이 없습니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N M
u1 v1
u2 v2
...
uM vM
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 15
- 0 ≤ M ≤ 25
- 1 ≤ u, v ≤ N, u ≠ v
- 중복 통로가 있을 수 있습니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
서로 연결된 기지 묶음의 수를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
5 3
1 2
2 3
4 5
4 0
```

## 예제 출력

```text
#1 2
#2 4
```

## 예제 해설

첫 번째의 묶음은 {1, 2, 3}과 {4, 5}로 두 개입니다.  
두 번째는 각 기지가 혼자 떨어져 있으므로 네 개입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
