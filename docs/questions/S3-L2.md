# S3-L2 · 반복문자 지우기

## 문제 설명

문자열에서 같은 문자가 바로 붙어 있는 두 글자를 지웁니다. 지운 부분의 앞뒤를 이어 붙이고, 다시 같은 글자 두 개가 붙으면 계속 지웁니다.  
  
한 번에 같은 글자 두 개를 지웁니다. 예를 들어 AAA에서는 AA를 지운 A 한 개가 남습니다. 더 이상 지울 수 없을 때 남은 문자열의 길이를 구하세요.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
공백 없는 문자열 S가 한 줄에 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
S
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ 문자열 길이 ≤ 1000
- 테스트에는 알파벳 대문자를 사용합니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
남은 문자열의 길이를 출력합니다. 모두 지워지면 0입니다.

```text
#tc answer
```

## 예제 입력

```text
2
CAAABBA
ABBA
```

## 예제 출력

```text
#1 1
#2 0
```

## 예제 해설

첫 번째는 AA, BB, AA를 차례로 지우면 C 한 글자가 남아 1입니다.  
두 번째는 모두 지워져 0입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
