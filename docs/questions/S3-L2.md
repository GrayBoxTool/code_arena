# S3-L2 · 돌아가는 인쇄 대기열

## 문제 설명

N개 문서가 처음 순서대로 인쇄 대기열에 들어 있습니다. 각 문서에는 중요도가 있으며, 처음 위치는 0번부터 N - 1번까지입니다.  
  
맨 앞 문서를 확인합니다. 현재 남은 문서 중 그보다 중요도가 높은 문서가 하나라도 있으면 맨 앞 문서를 맨 뒤로 옮깁니다. 그렇지 않으면 그 문서를 인쇄하고 대기열에서 제거합니다. 이 과정을 반복합니다.  
  
처음 K번 위치에 있던 문서가 몇 번째로 인쇄되는지 구하세요. 중요도가 같은 문서도 서로 다른 문서이며, 현재 대기열 순서에 따라 처리합니다. 인쇄 순서는 1부터 셉니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 문서 수 N과 추적할 문서의 처음 위치 K가 주어집니다.  
다음 줄에 처음 대기열 순서대로 중요도 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N K
p0 p1 ... p(N-1)
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 10
- 0 ≤ K < N
- 1 ≤ 각 중요도 ≤ 9

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
처음 K번 문서의 인쇄 순서를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
4 0
1 2 3 4
4 2
1 1 1 1
```

## 예제 출력

```text
#1 4
#2 3
```

## 예제 해설

첫 번째는 처음 3번 문서부터 역순으로 인쇄되어 처음 0번 문서는 네 번째입니다.  
두 번째는 중요도가 모두 같아 원래 순서대로 인쇄되므로 세 번째입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
