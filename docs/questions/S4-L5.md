# S4-L5 · 최약수

## 문제 설명

자연수 n 앞에 어떤 자연수의 십진수 표현을 붙여도, 만들어진 수가 항상 n으로 나누어떨어진다면 n을 최약수라고 부릅니다.  
  
예를 들어 5 앞에 3827을 붙인 38275는 5로 나누어떨어집니다. 이런 성질은 한 가지 앞자리 수가 아니라 모든 앞자리 수에 대해 성립해야 합니다.  
  
주어진 X 이하의 최약수 개수를 구하세요. 숫자는 선행 0 없는 십진수로 표현하며, 1도 조건을 만족합니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
한 줄에 자연수 X가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
X
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ X ≤ 1000000000

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
X 이하의 최약수 개수를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
2
100
```

## 예제 출력

```text
#1 2
#2 8
```

## 예제 해설

2 이하에서는 1과 2의 두 개입니다.  
100 이하에서는 1, 2, 5, 10, 20, 25, 50, 100의 여덟 개입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
