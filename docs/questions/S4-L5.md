# S4-L5 · 오른쪽 아래 보급로

## 문제 설명

N × N 격자의 각 칸에는 보급품 운반 비용이 적혀 있습니다. 왼쪽 위 칸에서 출발해 오른쪽 아래 칸으로 이동합니다.  
  
한 번에 오른쪽이나 아래쪽으로만 한 칸 이동할 수 있습니다. 위쪽, 왼쪽, 대각선 이동은 허용하지 않습니다.  
  
방문한 모든 칸의 비용을 더했을 때 가능한 최솟값을 구하세요. 출발 칸과 도착 칸의 비용도 포함합니다. N이 1이면 그 한 칸의 비용이 정답입니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 N이 주어집니다.  
다음 N줄에 각 행의 비용 N개가 공백으로 구분되어 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N
c11 c12 ... c1N
c21 c22 ... c2N
...
cN1 cN2 ... cNN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 8
- 0 ≤ 각 칸의 비용 ≤ 9

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
출발 칸부터 도착 칸까지의 최소 비용 합을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
3
1 2 9
4 1 2
9 3 1
1
7
```

## 예제 출력

```text
#1 7
#2 7
```

## 예제 해설

첫 번째는 오른쪽, 아래, 오른쪽, 아래로 이동하면 1 + 2 + 1 + 2 + 1 = 7입니다.  
두 번째는 출발과 도착이 같은 칸이며, 비용 7을 한 번 더합니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
