# S2-L2 · 연속 보급 구간

## 문제 설명

N일 동안의 날짜별 보급량이 주어집니다. 이 중 연속한 정확히 K일을 선택하려고 합니다.  
  
선택한 날짜들의 보급량을 모두 더했을 때 가능한 합 중 최솟값을 구하세요. 날짜 순서를 바꾸거나 선택한 기간 중간의 날짜를 건너뛸 수 없습니다.  
  
K가 1이면 하루 보급량 중 최솟값을, K가 N이면 전체 보급량의 합을 구하게 됩니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 전체 일수 N과 선택할 기간 K가 주어집니다.  
다음 줄에 날짜순으로 보급량 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N K
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ K ≤ N ≤ 1000
- 0 ≤ 각 보급량 ≤ 1000

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
연속한 K일의 보급량 합 중 최솟값을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
5 2
5 0 0 9 3
3 3
2 4 1
```

## 예제 출력

```text
#1 0
#2 7
```

## 예제 해설

첫 번째의 이틀 합은 5, 0, 9, 12이므로 정답은 0입니다.  
두 번째는 사흘을 모두 선택하므로 합 7입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
