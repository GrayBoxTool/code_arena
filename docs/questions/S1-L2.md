# S1-L2 · 날짜 계산기

## 문제 설명

같은 해의 두 날짜가 주어집니다. 두 번째 날짜가 첫 번째 날짜를 1일째로 셌을 때 며칠째인지 구하세요.  
  
첫날과 마지막 날을 모두 포함합니다. 윤년은 아니므로 2월은 28일까지입니다. 두 번째 날짜는 항상 첫 번째 날짜보다 뒤입니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
한 줄에 첫 번째 월·일과 두 번째 월·일이 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
m1 d1 m2 d2
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ 월 ≤ 12
- 각 날짜는 유효합니다.
- 월별 일수: 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
첫날을 포함한 날짜 수를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
3 1 3 31
1 1 12 31
```

## 예제 출력

```text
#1 31
#2 365
```

## 예제 해설

첫 번째는 3월 1일부터 31일까지 31일입니다.  
두 번째는 평년 전체이므로 365일입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
