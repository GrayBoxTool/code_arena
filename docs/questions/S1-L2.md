# S1-L2 · 보관함 잠금 로그

## 문제 설명

보관함의 잠금 로그가 소괄호와 대괄호로 기록되어 있습니다. 여는 괄호는 잠금 시작, 닫는 괄호는 잠금 종료를 뜻합니다.  
  
닫는 괄호가 나왔을 때에는 아직 닫히지 않은 가장 최근의 여는 괄호와 종류가 같아야 합니다. 소괄호는 소괄호끼리, 대괄호는 대괄호끼리 짝을 이룹니다.  
  
문자열을 모두 확인한 뒤 남는 여는 괄호가 없어야 올바른 로그입니다. 올바르면 YES, 그렇지 않으면 NO를 출력하세요. 괄호의 개수가 같더라도 닫히는 순서가 잘못되면 올바르지 않습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
각 테스트케이스마다 괄호 문자열 S가 한 줄에 주어집니다. 문자열 안에는 공백이 없습니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
S
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ 문자열 길이 ≤ 30
- 사용 문자는 (, ), [, ] 네 가지입니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
올바른 로그이면 YES, 아니면 NO를 출력합니다. 모두 대문자입니다.

```text
#tc answer
```

## 예제 입력

```text
2
([])
([)]
```

## 예제 출력

```text
#1 YES
#2 NO
```

## 예제 해설

첫 번째는 대괄호가 먼저 닫히고 소괄호가 닫히므로 YES입니다.  
두 번째는 대괄호가 열린 상태에서 소괄호가 먼저 닫히므로 NO입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
