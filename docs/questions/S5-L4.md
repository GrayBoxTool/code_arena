# S5-L4 · 올림픽 종목 투표

## 문제 설명

종목 1번부터 N번까지의 순서는 선호 순서입니다. 번호가 작을수록 더 선호하며, i번 종목의 개최 비용은 Ai입니다.  
  
위원 j는 예산 Bj 이하로 개최할 수 있는 종목 중 번호가 가장 작은 종목에 한 표를 줍니다. 위원마다 적어도 하나의 종목을 고를 수 있습니다.  
  
모든 투표 후 가장 많은 표를 받은 종목의 번호를 구하세요. 최다 득표 종목은 하나뿐인 입력만 주어집니다.



## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 설명에 따라 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 종목 수 N과 위원 수 M, 다음 줄에 종목 비용 N개, 그다음 줄에 위원 예산 M개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

## 제약조건

- 1 ≤ N, M ≤ 1000
- 1 ≤ Ai, Bj ≤ 1000
- 모든 위원이 투표할 수 있으며 최다 득표 종목은 유일합니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
선택된 종목 번호를 1부터 세어 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
4 3
5 3 1 4
4 3 2
3 1
9 8 1
1
```

## 예제 출력

```text
#1 2
#2 3
```

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
