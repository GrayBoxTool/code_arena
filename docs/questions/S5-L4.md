# S5-L4 · 이진 탐색 횟수

## 문제 설명

1번부터 P번까지의 페이지에서 두 목표 페이지 A와 B를 각각 이진 탐색합니다. 매 탐색은 left = 1, right = P에서 새로 시작합니다.  
  
center = (left + right) // 2를 계산하고 한 번 확인한 것으로 셉니다. center가 목표면 탐색을 마칩니다. 목표가 더 작으면 right = center - 1, 더 크면 left = center + 1로 바꾸고 반복합니다. //는 정수 나눗셈입니다.  
  
A와 B를 찾을 때 center를 계산한 횟수를 비교하세요. A가 더 적으면 A, B가 더 적으면 B, 같으면 TIE를 출력합니다. 목표를 찾은 마지막 계산도 횟수에 포함합니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
각 테스트케이스마다 한 줄에 전체 페이지 수 P와 두 목표 페이지 A, B가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
P A B
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ P ≤ 1000000
- 1 ≤ A, B ≤ P

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
A, B, TIE 중 하나를 대문자로 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
7 4 7
7 1 7
```

## 예제 출력

```text
#1 A
#2 TIE
```

## 예제 해설

첫 번째에서 4는 한 번 만에 찾고, 7은 center가 4 → 6 → 7로 세 번 계산되므로 A입니다.  
두 번째는 두 목표 모두 세 번 필요하므로 TIE입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
