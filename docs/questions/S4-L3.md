# S4-L3 · 섬의 수

## 문제 설명

N × N 지도가 주어집니다. 1은 땅, 0은 물을 나타냅니다.  
  
땅에서 상하좌우로 인접한 땅을 따라 이동할 수 있으면 같은 섬에 속합니다. 대각선으로만 닿은 땅은 서로 다른 섬입니다.  
  
지도에 있는 섬의 개수를 구하세요. 하나의 땅 칸도 섬 하나가 될 수 있으며, 땅이 전혀 없으면 섬의 개수는 0입니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 지도의 한 변 길이 N이 주어집니다.  
다음 N줄에는 길이 N인 0과 1 문자열이 주어집니다. 각 행 안에는 공백이 없습니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N
row1
row2
...
rowN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 6
- 각 지도 문자는 0 또는 1입니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
섬의 개수를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
3
110
010
001
2
00
00
```

## 예제 출력

```text
#1 2
#2 0
```

## 예제 해설

첫 번째는 왼쪽 위의 세 땅 칸이 한 섬이고 오른쪽 아래 한 칸이 다른 섬이므로 2입니다. 대각선 접촉은 연결이 아닙니다.  
두 번째는 땅이 없으므로 0입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
