# S4-L3 · 외로운 문자

## 문제 설명

소문자 문자열에서 같은 문자 두 개를 한 쌍으로 제거합니다. 서로 붙어 있지 않아도 짝지을 수 있습니다.  
  
가능한 모든 쌍을 제거한 뒤 남는 문자를 사전순으로 출력하세요. 각 문자는 남아도 최대 한 개입니다. 아무 문자도 남지 않으면 Good을 출력합니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
한 줄에 소문자 문자열이 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
S
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ 길이 ≤ 100
- a~z만 등장합니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
남는 문자를 사전순으로 붙여 출력합니다. 없다면 Good입니다.

```text
#tc answer
```

## 예제 입력

```text
2
xxyyzz
qnwerrewmq
```

## 예제 출력

```text
#1 Good
#2 mn
```

## 예제 해설

첫 번째는 모든 문자를 짝지을 수 있어 Good입니다.  
두 번째는 m과 n만 남으므로 mn입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
