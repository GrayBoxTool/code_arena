# FA-L1 · 야간 수송 구간

## 문제 설명

수송 차량은 정해진 순서대로 N개 구간을 통과합니다. 각 구간에는 연료 변화량이 기록되어 있습니다. 양수는 연료 소모, 음수는 연료 회수를 뜻합니다.  
  
관제사는 연속한 정확히 K개 구간을 하나의 관찰 구간으로 선택하려고 합니다. 선택한 구간의 연료 변화량을 모두 더했을 때, 그 합이 가장 작은 값을 구하세요.  
  
구간의 순서는 바꿀 수 없으며, 중간 구간을 건너뛸 수 없습니다. 합이 음수라면 음수 그대로 비교하고 출력합니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
각 테스트케이스의 첫 줄에 구간 수 N과 선택할 구간 수 K가 주어집니다.  
다음 줄에 N개의 연료 변화량이 이동 순서대로 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N K
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ K ≤ N ≤ 500
- 각 변화량은 -100 이상 100 이하의 정수입니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
연속한 K개 구간의 합 중 최솟값을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
5 3
4 -2 3 -5 6
3 3
-2 -3 1
```

## 예제 출력

```text
#1 -4
#2 -4
```

## 예제 해설

첫 번째 테스트케이스의 구간 합은 순서대로 5, -4, 4입니다. 따라서 -4를 출력합니다.  
두 번째는 세 구간을 모두 선택해야 하므로 합 -4를 출력합니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
