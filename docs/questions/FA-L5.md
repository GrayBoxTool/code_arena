# FA-L5 · 비용이 다른 네 색 깃발

## 문제 설명

N행 M열의 깃발을 위에서부터 W, B, R, G 순서의 네 가로 구역으로 나눕니다. 각 구역은 적어도 한 행이어야 하며, 구역 안의 모든 칸은 해당 색이어야 합니다.  
  
각 칸에는 별도의 재도색 비용이 있습니다. 목표 색과 현재 색이 같으면 비용 0, 다르면 그 칸의 재도색 비용을 냅니다. 어느 새 색으로 바꾸든 같은 칸의 비용은 같습니다.  
  
세 경계의 위치를 정해 전체 재도색 비용을 최소화하세요. 단순히 바꾸는 칸 수가 적은 배치가 최소 비용이라는 보장은 없습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 N과 M이 주어집니다.  
다음 N줄에 공백 없는 색 문자열, 이후 N줄에 각 칸의 비용이 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N M
현재 색 문자열 N줄
재도색 비용 M개씩 N줄
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 4 ≤ N ≤ 50
- 1 ≤ M ≤ 50
- 색은 W, B, R, G 중 하나입니다.
- 1 ≤ 각 재도색 비용 ≤ 9

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
조건을 만족하는 최소 재도색 비용을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
4 1
W
… (중간 줄 생략) …
6
4 1
G
R
… (중간 줄 생략) …
4
```

## 예제 출력

```text
#1 0
#2 10
```

## 예제 해설

첫 번째는 이미 네 구역의 색 순서가 맞아 0입니다.  
두 번째는 네 칸을 모두 칠해야 하므로 1+2+3+4=10입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
