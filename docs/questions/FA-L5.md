# FA-L5 · 서로 간섭하지 않는 보급소

## 문제 설명

일렬로 놓인 N개 보급소 중 정확히 K개를 가동하려고 합니다. 각 보급소를 가동하는 데 필요한 운송료가 주어집니다.  
  
바로 이웃한 두 보급소를 동시에 가동하면 간섭이 발생합니다. 따라서 선택한 두 보급소의 번호 차이가 1이어서는 안 됩니다. 1번과 N번은 이웃이 아닙니다.  
  
정확히 K개를 선택하면서 운송료 합이 가장 작아지도록 하세요. 선택 순서는 영향을 주지 않으며, 주어진 조건에서는 항상 선택이 가능합니다.  
  
[Lv4와의 연결 및 채점]  
문제의 규칙과 예제만으로 코드를 작성하고, Lv4를 풀기 전에도 제출할 수 있습니다. 처음부터 일반 테스트와 팀 전용 추가 테스트를 함께 채점합니다.  
  
팀 전용 테스트의 수열은 Lv4 팀 전용 입력의 정답 출력에서 가져옵니다. Lv4 정답 후에는 이 수열과 N, K가 화면에 공개되어, 실제 값으로 풀이를 검산할 수 있습니다. 공개 전후에 채점 데이터나 규칙이 바뀌지는 않습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
각 테스트케이스의 첫 줄에 보급소 수 N과 가동할 수 K가 주어집니다.  
다음 줄에 1번부터 N번까지의 운송료 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N K
c1 c2 ... cN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 4 ≤ N ≤ 15
- 1 ≤ K ≤ (N + 1) // 2
- 각 운송료는 1 이상 450 이하의 정수입니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
조건을 만족하는 최소 운송료 합을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
5 2
4 6 9 10 1
4 2
5 5 5 5
```

## 예제 출력

```text
#1 5
#2 10
```

## 예제 해설

첫 번째는 1번과 5번을 선택하면 서로 이웃하지 않고 운송료 합은 4 + 1 = 5입니다.  
두 번째는 가능한 어느 두 보급소를 선택해도 합이 10입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
