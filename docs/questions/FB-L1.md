# FB-L1 · 통신 신호의 안정 구간

## 문제 설명

수신기가 시간순으로 N개의 신호를 기록했습니다. 같은 값이 연속해서 나타나는 구간을 안정 구간이라고 부릅니다.  
  
가장 긴 안정 구간의 길이를 구하세요. 같은 신호가 떨어진 위치에서 다시 나타나더라도 두 구간을 합치지 않습니다. 신호를 지우거나 순서를 바꾸는 것도 허용하지 않습니다.  
  
예를 들어 2, 2, 5, 5, 5, 2의 가장 긴 안정 구간은 가운데의 5 세 개이므로 길이는 3입니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
각 테스트케이스의 첫 줄에 신호 개수 N이 주어집니다.  
다음 줄에 N개의 신호 값이 시간순으로 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 500
- 각 신호는 -100 이상 100 이하의 정수입니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
같은 값이 연속해서 등장하는 가장 긴 구간의 길이를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
6
2 2 5 5 5 2
1
-7
```

## 예제 출력

```text
#1 3
#2 1
```

## 예제 해설

첫 번째는 5가 연속으로 세 번 등장하므로 3입니다.  
두 번째는 신호가 하나뿐이며, 그 자체가 길이 1인 안정 구간입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
