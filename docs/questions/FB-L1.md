# FB-L1 · 기한 없는 할인권 배분

## 문제 설명

N장의 청구서와 K장의 할인권이 있습니다. 청구서 한 장에 할인권을 사용하면 그 청구서 금액의 절반을 할인받습니다. 할인액의 소수 부분은 버립니다.  
  
청구서 한 장에는 할인권을 최대 한 장만 쓸 수 있습니다. 할인권을 남겨도 되지만, 가능한 한 총 납부액이 작아지도록 사용하려고 합니다.  
  
모든 청구서의 금액이 주어질 때 최소 총 납부액을 구하세요.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 청구서 수 N과 할인권 수 K, 다음 줄에 청구 금액 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N K
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 100
- 0 ≤ K ≤ N
- 0 ≤ ai ≤ 10000

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
할인 후 총 납부액의 최솟값을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
4 2
9 8 3 0
3 0
1 2 3
```

## 예제 출력

```text
#1 12
#2 6
```

## 예제 해설

첫 번째는 9원과 8원 청구서에서 각각 4원씩 할인받아 20 - 8 = 12원입니다.  
두 번째는 할인권이 없어 6원입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 긴 예제는 두 테스트케이스에서 일부 줄만 표시합니다. …는 생략 표시이며 실제 데이터가 아닙니다. 전체 보기 기능은 제공하지 않습니다.
