# S4-L1 · 온도 상승량

## 문제 설명

온도를 시간순으로 N번 측정했습니다. 바로 이전 측정값보다 온도가 높아진 경우에만 그 상승량을 기록합니다.  
  
전체 측정 기록에서 상승량만 더한 값을 구하세요. 온도가 내려가거나 그대로인 경우에는 0을 더합니다. 첫 번째 측정값은 이전 값이 없으므로 계산에서 제외합니다.  
  
첫 온도와 마지막 온도의 차이를 구하는 것이 아니며, 각 이웃한 두 측정값 사이의 상승량을 따로 계산해야 합니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 측정 횟수 N이 주어집니다.  
다음 줄에 온도 N개가 측정 순서대로 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N
t1 t2 ... tN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 100
- -50 ≤ 각 온도 ≤ 50

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
상승한 양만 더한 합을 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
5
3 7 5 8 8
1
-10
```

## 예제 출력

```text
#1 7
#2 0
```

## 예제 해설

첫 번째는 3 → 7에서 4, 5 → 8에서 3만큼 상승하므로 합은 7입니다.  
두 번째는 비교할 측정값이 없으므로 0입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
