# S3-L3 · 목표 합 짝

## 문제 설명

서로 다른 정수 N개가 주어집니다. 이 중 두 수를 골라 합이 목표 값 V가 되도록 하려고 합니다.  
  
조건을 만족하는 서로 다른 쌍의 수를 구하세요. 같은 위치의 수를 두 번 사용할 수 없습니다. 두 수를 고르는 순서만 다른 경우는 같은 쌍입니다.  
  
예를 들어 2와 5를 고른 경우와 5와 2를 고른 경우는 한 쌍으로 셉니다. 음수와 0도 입력에 포함될 수 있습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 수의 개수 N과 목표 합 V가 주어집니다.  
다음 줄에 서로 다른 정수 N개가 주어집니다. 테스트케이스 수 T와 목표 합 V를 구분하세요.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N V
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 2 ≤ N ≤ 30
- -100 ≤ V ≤ 100
- -50 ≤ 각 수 ≤ 50
- 수열의 값은 모두 서로 다릅니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
합이 V인 두 수의 쌍 개수를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
4 0
-2 -1 1 2
3 100
-50 0 50
```

## 예제 출력

```text
#1 2
#2 0
```

## 예제 해설

첫 번째는 (-2, 2), (-1, 1)의 두 쌍입니다.  
두 번째에서 50을 두 번 고를 수는 없으므로 정답은 0입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
