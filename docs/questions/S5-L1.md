# S5-L1 · 신호 범위 검사

## 문제 설명

정수 신호 N개 중 허용 범위 안에 있는 신호가 몇 개인지 확인하려고 합니다. 허용 범위는 L 이상 R 이하입니다.  
  
각 신호를 따로 검사하여 범위 안에 있으면 하나로 셉니다. 값이 같더라도 서로 다른 위치에 등장했다면 각각 셉니다.  
  
경계값 L과 R도 허용 범위에 포함합니다. 허용되는 신호가 없으면 0을 출력하세요.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 신호 수 N과 범위의 최솟값 L, 최댓값 R이 주어집니다.  
다음 줄에 신호 N개가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N L R
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 100
- -50 ≤ L ≤ R ≤ 50
- -50 ≤ 각 신호 값 ≤ 50

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
허용 범위에 포함되는 신호의 개수를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
6 -2 3
-3 -2 0 3 3 4
3 5 5
4 5 6
```

## 예제 출력

```text
#1 4
#2 1
```

## 예제 해설

첫 번째는 -2, 0, 3, 3의 네 신호를 셉니다.  
두 번째는 값이 정확히 5인 신호 하나만 셉니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
