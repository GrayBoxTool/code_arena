# FA-L3 · 탐사 트리의 번호표

## 문제 설명

노드 번호가 1부터 N까지인 완전 이진 트리에 번호표를 붙입니다. 노드 i의 왼쪽 자식 번호는 2 × i, 오른쪽 자식 번호는 2 × i + 1입니다. 번호가 N보다 큰 자식은 존재하지 않습니다.  
  
트리를 왼쪽 자식 부분, 현재 노드, 오른쪽 자식 부분 순서로 방문합니다. 이 방문 순서를 중위 순회라고 합니다. 첫 번째 방문한 노드에 1, 두 번째에 2를 저장하는 방식으로 N까지 저장합니다.  
  
모든 값을 저장한 뒤, 루트인 1번 노드와 K번 노드에 저장된 값을 구하세요. 노드 번호와 그 노드에 저장되는 값은 서로 다를 수 있습니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
각 테스트케이스마다 한 줄에 노드 수 N과 확인할 노드 번호 K가 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N K
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ K ≤ N ≤ 500

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
1번 노드의 값과 K번 노드의 값을 순서대로 출력합니다. 두 값 사이는 공백 한 칸으로 구분합니다.

```text
#tc root_value node_value
```

## 예제 입력

```text
2
5 2
1 1
```

## 예제 출력

```text
#1 4 2
#2 1 1
```

## 예제 해설

첫 번째의 방문 순서는 노드 4, 2, 5, 1, 3입니다. 노드 1에는 4가, 노드 2에는 2가 저장되어 4 2를 출력합니다.  
두 번째는 루트 하나뿐이므로 1 1입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
