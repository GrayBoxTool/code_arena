# S3-L1 · 연결하지 않은 전구

## 문제 설명

전구 N개가 왼쪽부터 일렬로 놓여 있습니다. 0은 꺼진 전구, 1은 켜진 전구를 나타냅니다.  
  
서로 바로 이웃한 두 전구 중 왼쪽이 1이고 오른쪽이 0인 쌍의 수를 구하세요. 왼쪽부터 오른쪽 방향으로만 조건을 확인합니다.  
  
첫 전구와 마지막 전구는 서로 이웃하지 않습니다. N이 1이면 비교할 쌍이 없으므로 정답은 0입니다.

## 입력

전체 입력의 첫 줄에는 테스트케이스 수 T가 주어집니다. (1 ≤ T ≤ 3)  
이후 아래 형식의 테스트케이스가 T개 이어집니다. 테스트케이스 사이에 빈 줄은 없습니다.  
  
첫 줄에 전구 수 N이 주어집니다.  
다음 줄에는 전구 상태 N개가 공백으로 구분되어 주어집니다.  
  
한 줄의 여러 값은 공백으로 구분됩니다. 문자열·지도 행의 공백 여부는 위 설명을 따르세요.

### 테스트케이스 하나의 입력 형식

```text
N
a1 a2 ... aN
```

위의 이름은 자리 표시자이며, `...`는 반복을 뜻합니다. 실제 입력에는 숫자·문자열만 들어 있습니다.

## 제약조건

- 1 ≤ N ≤ 100
- 각 상태는 0 또는 1입니다.

## 출력

각 테스트케이스마다 한 줄에 #과 테스트케이스 번호 tc를 붙여 출력하고, 공백 한 칸 뒤에 정답을 출력합니다.  
tc는 1부터 시작합니다. 예: #1 10  
  
(1, 0) 순서로 나타나는 인접한 쌍의 수를 출력합니다.

```text
#tc answer
```

## 예제 입력

```text
2
6
1 0 1 0 0 1
1
1
```

## 예제 출력

```text
#1 2
#2 0
```

## 예제 해설

첫 번째는 (1번, 2번), (3번, 4번)의 두 쌍입니다. 마지막 전구에서 첫 전구로 이어 세지 않습니다.  
두 번째는 비교할 이웃이 없으므로 0입니다.

## 공백과 줄바꿈 안내

코드 블록 안의 띄어쓰기는 실제 공백이며, 각 행은 실제 줄바꿈입니다. 게임 화면의 **공백·줄바꿈 표시 보기**에서는 공백을 `␠`, 줄바꿈을 `↵`로 확인할 수 있습니다. 이 표시 기호를 입력하거나 출력하지 마세요.
