# S2-L1 · 모범 풀이

```python
def solve_case():
    n = int(input())
    a = list(map(int, input().split()))
    seen = set()
    ans = -1
    for x in a:
        if x in seen:
            ans = x
            break
        seen.add(x)
    print(ans)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```
