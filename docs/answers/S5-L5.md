# S5-L5 · 모범 풀이

```python
def solve_case():
    n,m=map(int,input().split())
    d=[0]*(n+1)
    for _ in range(m):
        s,p=map(int,input().split())
        for v in range(n,s-1,-1): d[v]=max(d[v],d[v-s]+p)
    print(d[n])
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```
