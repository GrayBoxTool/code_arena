# S2-L4 · 모범 풀이

```python
def solve_case():
    s=input().strip()
    h=int(input())
    a=list(map(int,input().split()))
    f=[0]*(len(s)+1)
    for x in a: f[x]+=1
    out="-"*f[0]
    for i,c in enumerate(s,1): out+=c+"-"*f[i]
    print(out)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```
