# S2-L5 · 모범 풀이

```python
def solve_case():
    n, k = map(int, input().split())

    def count(x):
        if x > n:
            return 0
        return 1 + count(x * 2) + count(x * 2 + 1)
    print(count(k))
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```
