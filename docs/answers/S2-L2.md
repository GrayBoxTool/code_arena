# S2-L2 · 모범 풀이

```python
def solve_case():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    now = sum(a[:k])
    ans = now
    for i in range(k, n):
        now += a[i] - a[i - k]
        ans = min(ans, now)
    print(ans)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```
