# S2-L2 · 모범 풀이

```python
def solve_case():
    n,m=map(int,input().split())
    a=list(map(int,input().split()))
    b=list(map(int,input().split()))
    if n>m: a,b=b,a
    print(max(sum(x*b[i+j] for j,x in enumerate(a)) for i in range(len(b)-len(a)+1)))
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```
