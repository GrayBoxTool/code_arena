# S3-L4 · 모범 풀이

```python
def solve_case():
    n,m=map(int,input().split())
    p=set()
    for _ in range(n):
        s=input().strip()
        for i in range(1,len(s)+1): p.add(s[:i])
    print(sum(input().strip() in p for _ in range(m)))
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```
