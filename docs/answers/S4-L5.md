# S4-L5 · 모범 풀이

```python
def solve_case():
    x=int(input())
    ans=0
    a=1
    while a<=x:
        b=a
        while b<=x:
            if 10**len(str(b))%b==0: ans+=1
            b*=5
        a*=2
    print(ans)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```
