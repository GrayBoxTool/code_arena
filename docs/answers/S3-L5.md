# S3-L5 · 모범 풀이

```python
def solve_case():
    n, v = map(int, input().split())
    a = list(map(int, input().split()))
    sums = [0]
    for x in a:
        sums += [s + x for s in sums]
    possible = [s for s in sums if s >= v]
    print(min(possible) if possible else -1)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```
