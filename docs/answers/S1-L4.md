# S1-L4 · 모범 풀이

```python
def solve_case():
    n = int(input())
    jobs = sorted((tuple(map(int, input().split())) for _ in range(n)), key=lambda x: x[1])
    end = -1
    count = 0
    for s, e in jobs:
        if s >= end:
            end = e
            count += 1
    print(count)
T = int(input())
for tc in range(1, T + 1):
    print(f'#{tc} ', end='')
    solve_case()
```
